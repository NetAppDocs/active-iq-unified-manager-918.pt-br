= Atualize o Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode atualizar o Active IQ Unified Manager para a versão 9.18 somente a partir das versões 9.14 ou 9.16.

Durante o processo de atualização, o Unified Manager ficará indisponível. Você deve concluir todas as operações em andamento antes de atualizar o Unified Manager.

Se o Unified Manager estiver emparelhado com uma instância do OnCommand Workflow Automation e houver novas versões de software disponíveis para ambos os produtos, você deverá desconectar os dois produtos e, em seguida, configurar uma nova conexão do Workflow Automation após realizar as atualizações. Se você estiver atualizando apenas um dos produtos, deverá fazer login no Workflow Automation após a atualização e verificar se ele ainda está obtendo dados do Unified Manager.

[NOTE]
====
Se o seu sistema foi atualizado do Unified Manager 9.7, você não pode atualizar diretamente da versão 9.14 para a 9.18 devido a alterações no sistema de arquivos nas versões do Debian. Em vez disso, siga este caminho de atualização: 9.14 -> 9.16P2 -> 9.18.

====
.Passos
. Siga as etapas em link:task_download_unified_manager_iso_image_vapp.html["Baixe a imagem ISO do Unified Manager"].
. Além disso, siga os passos descritos em link:task_upgrade_unified_manager_virtual_appliance_vapp.html["Atualizar o Unified Manager"].
