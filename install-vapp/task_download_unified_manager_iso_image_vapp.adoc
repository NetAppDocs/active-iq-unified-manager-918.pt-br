= Baixe o arquivo de atualização do Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Antes de atualizar o Unified Manager, faça o download do arquivo de atualização do Unified Manager no site de suporte da NetApp.

.Antes de começar
Você deve ter credenciais de login para o site de suporte da NetApp.

.Passos
. Faça login no site de suporte da NetApp:
+
https://mysupport.netapp.com/site/products/all/details/activeiq-unified-manager/downloads-tab["NetApp site de suporte"]

. Acesse a página de download para atualizar o Unified Manager no VMware vSphere.
. Baixe a  `.iso`imagem para atualização e salve-a em um diretório local ou de rede acessível ao seu vSphere Client.
. Verifique o checksum para garantir que o software foi baixado corretamente.
