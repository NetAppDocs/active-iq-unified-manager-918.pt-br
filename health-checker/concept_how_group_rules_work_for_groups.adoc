= Entenda como as regras de grupo funcionam para grupos no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Uma regra de grupo é um critério que você define para permitir que objetos de armazenamento (volumes, clusters ou SVMs) sejam incluídos em um grupo específico. Você pode usar grupos de condições ou condições para definir uma regra de grupo para um grupo.

* Você deve associar uma regra de grupo a um grupo.
* Você deve associar um tipo de objeto a uma regra de grupo; apenas um tipo de objeto pode ser associado a uma regra de grupo.
* Os objetos de armazenamento são adicionados ou removidos do grupo após cada ciclo de monitoramento ou quando uma regra é criada, editada ou excluída.
* Uma regra de grupo pode ter um ou mais grupos de condições, e cada grupo de condições pode ter uma ou mais condições.
* Os objetos de armazenamento podem pertencer a vários grupos com base nas regras de grupo que você criar.




[[conditions]]
== Condições

Você pode criar vários grupos de condições, e cada grupo de condições pode ter uma ou mais condições. Você pode aplicar todos os grupos de condições definidos em uma regra de grupo para grupos para especificar quais objetos de storage estão incluídos no grupo.

As condições dentro de um grupo de condições são executadas usando o operador lógico AND. Todas as condições em um grupo de condições devem ser atendidas. Ao criar ou modificar uma regra de grupo, uma condição é criada para aplicar, selecionar e agrupar apenas os objetos de storage que satisfazem todas as condições do grupo de condições. Você pode usar várias condições dentro de um grupo de condições quando quiser restringir o escopo de quais objetos de storage incluir em um grupo.

Você pode criar condições com objetos de storage usando os seguintes operandos e operador e especificando o valor necessário.

[cols="2*"]
|===
| Tipo de objeto de armazenamento | Operandos aplicáveis 


 a| 
Volume
 a| 
* Nome do objeto
* Nome do cluster proprietário
* Nome da SVM proprietária
* Anotações




 a| 
SVM
 a| 
* Nome do objeto
* Nome do cluster proprietário
* Anotações




 a| 
Cluster
 a| 
* Nome do objeto
* Anotações


|===
Ao selecionar a anotação como operando para qualquer objeto de armazenamento, o operador "`Is`" estará disponível. Para todos os outros operandos, você pode selecionar "`Is`" ou "`Contains`" como operador.

* Operando
+
A lista de operandos no Unified Manager muda de acordo com o tipo de objeto selecionado. A lista inclui o nome do objeto, o nome do cluster proprietário, o nome da SVM proprietária e as anotações que você define no Unified Manager.

* Operador
+
A lista de operadores muda com base no operando selecionado para uma condição. Os operadores suportados no Unified Manager são "`Is`" e "`Contains`".

+
Ao selecionar o operador "`Is`", a condição é avaliada para verificar se o valor do operando corresponde exatamente ao valor fornecido para o operando selecionado.

+
Ao selecionar o operador "`Contains`", a condição é avaliada para atender a um dos seguintes critérios:

+
** O valor do operando corresponde exatamente ao valor fornecido para o operando selecionado
** O valor do operando contém o valor fornecido para o operando selecionado


* Valor
+
O campo de valor muda com base no operando selecionado.





[[example-of-a-group-rule-with-conditions]]
== Exemplo de uma regra de grupo com condições

Considere um grupo de condições para um volume com as seguintes duas condições:

* O nome contém "`vol`"
* O nome da SVM é "`data_svm`"


Este grupo de condições seleciona todos os volumes que incluem "`vol`" em seus nomes e que estão hospedados em SVMs com o nome "`data_svm`".



[[condition-groups]]
== Grupos de condições

Os grupos de condições são executados usando o operador lógico OU e, em seguida, aplicados aos objetos de armazenamento. Os objetos de armazenamento devem satisfazer um dos grupos de condições para serem incluídos em um grupo. Os objetos de armazenamento de todos os grupos de condições são combinados. Você pode usar grupos de condições para ampliar o escopo dos objetos de armazenamento a serem incluídos em um grupo.



[[example-of-a-group-rule-with-condition-groups]]
== Exemplo de uma regra de grupo com grupos de condição

Considere dois grupos de condições para um volume, com cada grupo contendo as seguintes duas condições:

* Grupo de condição 1
+
** O nome contém "`vol`"
** O nome da SVM é "`data_svm`" O grupo de condições 1 seleciona todos os volumes que incluem "`vol`" em seus nomes e que estão hospedados em SVMs com o nome "`data_svm`".


* Grupo de condição 2
+
** O nome contém "`vol`"
** O valor da anotação data-priority é "`critical`" O grupo de condições 2 seleciona todos os volumes que incluem "`vol`" nos nomes e que têm o valor de anotação data-priority como "`critical`".




Quando você aplica uma regra de grupo que contém estes dois grupos de condições a objetos de armazenamento, os seguintes objetos de armazenamento são adicionados ao grupo selecionado:

* Todos os volumes que incluem "`vol`" em seus nomes e que estão hospedados no SVM com o nome "`data_svm`".
* Todos os volumes que incluem "`vol`" em seus nomes e que são anotados com o valor de anotação de prioridade de dados "`critical`".
