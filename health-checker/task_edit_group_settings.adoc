= Editar grupos no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode editar o nome e a descrição de um grupo que você criou no Unified Manager.

.Antes de começar
Você precisa ter a função de Application Administrator ou Storage Administrator.

Ao editar um grupo para atualizar o nome, você deve especificar um nome exclusivo; não é possível usar um nome de grupo existente.

.Passos
. No painel de navegação esquerdo, clique em *Gerenciamento de armazenamento* > *Grupos*.
. Na aba *Grupos*, selecione o grupo que deseja editar e clique em *Editar*.
. Na caixa de diálogo *Editar Grupo*, altere o nome, a descrição ou ambos do grupo.
. Clique em *Salvar*.
