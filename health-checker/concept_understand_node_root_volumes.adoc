= Compreenda os volumes raiz dos nós no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode monitorar o volume raiz do nó usando o Unified Manager. A melhor prática é que o volume raiz do nó tenha capacidade suficiente para evitar que o nó saia do ar.

Quando a capacidade usada do volume raiz do nó excede 80 por cento da capacidade total do volume raiz do nó, o evento "Node Root Volume Space Nearly Full" é gerado. Você pode configurar um alerta para o evento e receber uma notificação. Você pode tomar as medidas apropriadas para evitar que o nó fique inativo usando o ONTAP System Manager ou a ONTAP CLI.


NOTE: A funcionalidade de monitoramento de volumes raiz de nós não está disponível se os clusters executarem a versão ONTAP 9.14.1 ou posterior.
