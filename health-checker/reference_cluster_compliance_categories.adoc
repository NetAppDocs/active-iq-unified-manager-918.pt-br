= Compreenda as categorias de conformidade de cluster no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Esta tabela descreve os parâmetros de conformidade de segurança do cluster que o Unified Manager avalia, a recomendação da NetApp e se o parâmetro afeta a determinação geral de se o cluster está em conformidade ou não.

Ter SVMs não conformes em um cluster afetará o valor de conformidade do cluster. Portanto, em alguns casos, pode ser necessário corrigir um problema de segurança em uma SVM antes que a segurança do cluster seja considerada em conformidade.

Observe que nem todos os parâmetros listados abaixo aparecem em todas as instalações. Por exemplo, se você não tiver clusters emparelhados ou se tiver desativado o AutoSupport em um cluster, não verá os itens "Emparelhamento de Cluster" ou "AutoSupport HTTPS Transport" na página da interface de usuário.

[cols="4*"]
|===
| Parâmetro | Descrição | Recomendação | Afeta a conformidade do cluster 


 a| 
FIPS global
 a| 
Indica se o modo de conformidade Global FIPS (Federal Information Processing Standard) 140-2 está ativado ou desativado. Quando o FIPS está ativado, o TLSv1 e o SSLv3 são desativados, e somente o TLSv1.1 e o TLSv1.2 são permitidos.
 a| 
Habilitado
 a| 
Sim



 a| 
Telnet
 a| 
Indica se o acesso Telnet ao sistema está habilitado ou desabilitado. NetApp recomenda o Secure Shell (SSH) para acesso remoto seguro.
 a| 
Desabilitado
 a| 
Sim



 a| 
Configurações SSH inseguras
 a| 
Indica se o SSH usa cifras inseguras, por exemplo cifras que começam com *cbc.
 a| 
Não
 a| 
Sim



 a| 
Banner de login
 a| 
Indica se o banner de login está habilitado ou desabilitado para os usuários que acessam o sistema.
 a| 
Habilitado
 a| 
Sim



 a| 
Interconexão de clusters
 a| 
Indica se a comunicação entre clusters emparelhados é criptografada ou não criptografada. A criptografia deve estar configurada nos clusters de origem e de destino para que este parâmetro seja considerado em conformidade.
 a| 
Criptografado
 a| 
Sim



 a| 
Protocolo de Tempo de Rede
 a| 
Indica se o cluster possui um ou mais servidores NTP configurados. Para redundância e melhor serviço, a NetApp recomenda que você associe pelo menos três servidores NTP ao cluster.
 a| 
Configurado
 a| 
Sim



 a| 
OCSP
 a| 
A partir da versão 9.14.1, o Active IQ Unified Manager fornece informações de status do Online Certificate Status Protocol (OCSP) no nível da máquina virtual de armazenamento (SVM, anteriormente conhecida como Vserver). Isso significa que a validação de OCSP é aplicada a todas as conexões SSL/TLS feitas com a SVM e garante a integridade e a validade dos certificados usados nessas conexões.
 a| 
Habilitado
 a| 
Não



 a| 
Log de auditoria remoto
 a| 
Indica se o encaminhamento de logs (Syslog) está criptografado ou não criptografado.
 a| 
Criptografado
 a| 
Sim



 a| 
AutoSupport Transporte HTTPS
 a| 
Indica se o HTTPS é usado como protocolo de transporte padrão para enviar mensagens do AutoSupport ao suporte da NetApp.
 a| 
Habilitado
 a| 
Sim



 a| 
Usuário administrador padrão
 a| 
Indica se o usuário administrador padrão (incorporado) está ativado ou desativado. NetApp recomenda bloquear (desativar) todas as contas incorporadas desnecessárias.
 a| 
Desabilitado
 a| 
Sim



 a| 
Usuários SAML
 a| 
Indica se o SAML está configurado. O SAML permite que você configure a autenticação multifator (MFA) como método de login para single sign-on.
 a| 
Não
 a| 
Não



 a| 
Usuários do Active Directory
 a| 
Indica se o Active Directory está configurado. O Active Directory e o LDAP são os mecanismos de autenticação preferenciais para usuários que acessam clusters.
 a| 
Não
 a| 
Não



 a| 
Usuários LDAP
 a| 
Indica se o LDAP está configurado. O Active Directory e o LDAP são os mecanismos de autenticação preferenciais para usuários que gerenciam clusters, em comparação com usuários locais.
 a| 
Não
 a| 
Não



 a| 
Usuários de certificado
 a| 
Indica se um usuário com certificado está configurado para fazer login no cluster.
 a| 
Não
 a| 
Não



 a| 
Usuários locais
 a| 
Indica se os usuários locais estão configurados para fazer login no cluster.
 a| 
Não
 a| 
Não



 a| 
Shell remoto
 a| 
Indica se o RSH está habilitado. Por motivos de segurança, o RSH deve ser desabilitado. O Secure Shell (SSH) para acesso remoto seguro é o método preferencial.
 a| 
Desabilitado
 a| 
Sim



 a| 
MD5 em uso
 a| 
Indica se as contas de usuário do ONTAP usam a função de hash MD5, menos segura. A migração das contas de usuário com hash MD5 para uma função de hash criptográfica mais segura, como SHA-512, é recomendada.
 a| 
Não
 a| 
Sim



 a| 
Tipo de emissor do certificado
 a| 
Indica o tipo de certificado digital utilizado.
 a| 
Assinado pela CA
 a| 
Não
