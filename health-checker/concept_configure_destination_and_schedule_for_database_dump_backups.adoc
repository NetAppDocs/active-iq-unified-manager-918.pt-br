= Configure as definições de backup de dump do banco de dados no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode configurar as definições de backup de dump do banco de dados do Unified Manager para definir o caminho de backup do banco de dados, a contagem de retenção e a programação de backups. Você pode ativar backups agendados diários ou semanais. Por padrão, os backups agendados estão desativados, mas você deve definir uma programação de backups.

.Antes de começar
* Você precisa ter a função de Operador, Administrador de Aplicativos ou administrador de storage.
* Você deve ter no mínimo 150 GB de espaço disponível no local que você definir como o caminho de backup.
+
Recomenda-se que você use um local remoto externo ao sistema host do Unified Manager.

* Quando o Unified Manager estiver instalado em um sistema Linux e você estiver usando o backup do MySQL, certifique-se de que as seguintes permissões e propriedades estejam definidas no diretório de backup.
+
Permissões: 0750, Propriedade: jboss:maintenance

* Quando o Unified Manager estiver instalado em um sistema Windows e usando o backup do MySQL, certifique-se de que somente o administrador tenha acesso ao diretório de backup.


A primeira execução de um backup exige mais tempo do que os backups subsequentes porque o primeiro backup é um backup completo. Um backup completo pode ter mais de 1 GB e levar de três a quatro horas. Os backups subsequentes são incrementais e exigem menos tempo.

[NOTE]
====
* Se você achar que o número de arquivos de backup incremental é muito grande para o espaço alocado para backups, pode fazer um backup completo periodicamente para substituir o backup antigo e seus arquivos incrementais. Como outra opção, você pode fazer um backup usando cópias Snapshot.
* O backup realizado durante os primeiros 15 dias após a adição de um novo cluster pode não ser preciso o suficiente para obter dados históricos de desempenho.


====
.Passos
. No painel de navegação esquerdo, clique em *Geral* > *backup do banco de dados*.
. Na página *Backup do Banco de Dados*, clique em *Configurações de Backup*.
. Configure os valores apropriados para um caminho de backup, o número de retenções e o agendamento.
+
O valor padrão para a contagem de retenção é 10; você pode usar 0 para criar backups ilimitados.

. Selecione o botão *Agendado Diariamente* ou *Agendado Semanalmente* e em seguida especifique os detalhes do agendamento.
. Clique em *Aplicar*.


Os arquivos de backup do banco de dados são criados com base no agendamento. Você pode ver os arquivos de backup disponíveis na página Backup do Banco de Dados.
