= Veja o status de criptografia de todos os volumes no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode visualizar uma lista de todos os volumes e seus respectivos status atuais de criptografia para determinar se os dados em seus volumes estão adequadamente protegidos contra o acesso por usuários não autorizados.

.Antes de começar
Você precisa ter a função de Operador, Administrador de Aplicativos ou administrador de storage.

Os tipos de criptografia que podem ser aplicados a um volume são:

* Software: volumes protegidos usando as soluções de criptografia de software NetApp Volume Encryption (NVE) ou NetApp Aggregate Encryption (NAE).
* Hardware: volumes protegidos usando criptografia de hardware do NetApp Storage Encryption (NSE).
* Software e hardware: volumes protegidos por criptografia de software e de hardware.
* Nenhum: volumes que não estão criptografados.


.Passos
. No painel de navegação à esquerda, clique em *Armazenamento* > *Volumes*.
. No menu Exibir, selecione *Saúde* > *Criptografia de volumes*
. Na visualização *Health: Volumes Encryption*, classifique pelo campo *Encryption Type* ou use o filtro para exibir volumes que tenham um tipo de criptografia específico ou que não estejam criptografados (*Encryption Type* de "`None`").
