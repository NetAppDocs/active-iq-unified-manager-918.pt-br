= Entenda como os scripts funcionam com alertas no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode associar um alerta ao seu script para que ele seja executado quando um alerta for acionado para um evento no Unified Manager. Você pode usar os scripts para resolver problemas com objetos de armazenamento ou identificar quais objetos de armazenamento estão gerando os eventos.

Quando um alerta é gerado para um evento no Unified Manager, um e-mail de alerta é enviado aos destinatários especificados. Se você associou um alerta a um script, o script é executado. Você pode obter os detalhes dos argumentos passados para o script no e-mail de alerta.

[NOTE]
====
Se você criou um script personalizado e o associou a um alerta para um tipo de evento específico, as ações serão executadas com base no seu script personalizado para esse tipo de evento, e as ações "Fix it" não estarão disponíveis por padrão na página Management Actions nem no dashboard do Unified Manager.

====
O script utiliza os seguintes argumentos para execução:

* `-eventID`
* `-eventName`
* `-eventSeverity`
* `-eventSourceID`
* `-eventSourceName`
* `-eventSourceType`
* `-eventState`
* `-eventArgs`


Você pode usar os argumentos em seus scripts e coletar informações sobre eventos relacionados ou modificar objetos de armazenamento.



[[example-for-obtaining-arguments-from-scripts]]
== Exemplo de obtenção de argumentos a partir de scripts

[listing]
----
print "$ARGV[0] : $ARGV[1]\n"
print "$ARGV[7] : $ARGV[8]\n"
----
Quando um alerta é gerado, este script é executado e a seguinte saída é exibida:

[listing]
----
-eventID : 290
-eventSourceID : 4138
----
