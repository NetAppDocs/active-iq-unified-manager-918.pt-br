= Excluir cópias Snapshot no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode excluir uma cópia Snapshot para economizar espaço ou liberar espaço de disco, ou pode excluir a cópia Snapshot se ela não for mais necessária.

.Antes de começar
Você precisa ter a função de Application Administrator ou Storage Administrator.

O volume deve estar online.

Para excluir uma cópia Snapshot que esteja em uso ou bloqueada, você deve ter liberado a cópia Snapshot do aplicativo que a estava utilizando.

* Não é possível excluir a cópia Snapshot de base em um volume pai se um volume FlexClone estiver usando essa cópia Snapshot.
+
A cópia Snapshot de base é a cópia Snapshot usada para criar o volume FlexClone e exibe o status `Busy` e a dependência do aplicativo como `Busy, Vclone` no volume pai.

* Não é possível excluir uma cópia Snapshot bloqueada que esteja sendo usada em uma relação do SnapMirror.
+
A cópia Snapshot está bloqueada e é necessária para a próxima atualização.



.Passos
. No painel de navegação à esquerda, clique em *Armazenamento* > *Volumes*.
. Na visualização *Saúde: todos os volumes*, selecione o volume que contém as cópias Snapshot que você deseja visualizar.
+
A lista de cópias Snapshot é exibida.

. Na página de detalhes de *Volume / Health*, clique na aba *Capacity*.
. No painel *Details* da guia *Capacity*, na seção Outros detalhes, clique no link ao lado de *Snapshot Copies*.
+
O número de cópias do Snapshot é um link que exibe a lista de cópias do Snapshot.

. Na visualização *Cópias Snapshot*, selecione as cópias Snapshot que você deseja excluir e clique em *Excluir selecionados*.
