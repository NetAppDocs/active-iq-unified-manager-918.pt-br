= Backup e restauração usando um dump do banco de dados MySQL no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Um backup de dump do banco de dados MySQL é uma cópia do banco de dados e dos arquivos de configuração do Active IQ Unified Manager que você pode usar em caso de falha do sistema ou perda de dados. Você pode agendar um backup para ser gravado em um destino local ou em um destino remoto. É altamente recomendável que você defina um local remoto externo ao sistema host do Active IQ Unified Manager.

[NOTE]
====
O dump do banco de dados MySQL é o mecanismo de backup padrão quando o Unified Manager é instalado em um servidor Linux ou Windows. No entanto, se o Unified Manager estiver gerenciando um grande número de clusters e nós, ou se seus backups do MySQL estiverem levando muitas horas para serem concluídos, você poderá fazer backup usando cópias Snapshot. Essa funcionalidade está disponível no Red Hat Enterprise Linux e no Windows.

====
Um backup de dump do banco de dados consiste em um único arquivo no diretório de backup e um ou mais arquivos no diretório do repositório do banco de dados. O arquivo no diretório de backup é muito pequeno porque contém apenas um ponteiro para os arquivos localizados no diretório do repositório do banco de dados que são necessários para recriar o backup.

Na primeira vez que você gera um backup, um único arquivo é criado no diretório de backup e um arquivo de backup completo é criado no diretório do repositório do banco de dados. Na próxima vez que você gera um backup, um único arquivo é criado no diretório de backup e um arquivo de backup incremental é criado no diretório do repositório do banco de dados, contendo as diferenças em relação ao arquivo de backup completo. Esse processo continua à medida que você cria backups adicionais, até a configuração máxima de retenção, conforme mostrado na figura a seguir.

image::../media/database_backup.gif[Um diagrama que mostra três arquivos de diretório de backup apontando para arquivos completos e incrementais no repositório de banco de dados]

[NOTE]
====
Não renomeie nem remova nenhum dos arquivos de backup nesses dois diretórios, caso contrário qualquer operação de restauração subsequente falhará.

====
Se você gravar seus arquivos de backup no sistema local, deverá iniciar um processo para copiar esses arquivos de backup para um local remoto, para que estejam disponíveis caso ocorra um problema no sistema que exija uma restauração completa.

Antes de iniciar uma operação de backup, o Active IQ Unified Manager realiza uma verificação de integridade para verificar se todos os arquivos e diretórios de backup necessários existem e podem ser gravados. Ele também verifica se há espaço suficiente no sistema para criar o arquivo de backup.
