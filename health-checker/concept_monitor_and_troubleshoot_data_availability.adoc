= Monitore e solucione problemas de disponibilidade de dados no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
O Unified Manager monitora a confiabilidade com que os usuários autorizados podem acessar seus dados armazenados, alerta você sobre condições que bloqueiam ou impedem esse acesso e permite que você diagnostique essas condições, além de atribuir e acompanhar sua resolução.

Os tópicos de fluxo de trabalho de disponibilidade nesta seção descrevem exemplos de como um administrador de storage pode usar a interface da Web do Unified Manager para descobrir, diagnosticar e atribuir para resolução condições de hardware e software que afetam negativamente a disponibilidade de dados.
