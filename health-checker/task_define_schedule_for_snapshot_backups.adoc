= Defina um cronograma de backup para Linux e Windows no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode usar a interface do usuário do Unified Manager para configurar a programação em que as cópias Snapshot do Unified Manager são criadas.

.Antes de começar
* Você precisa ter a função de Operador, Administrador de Aplicativos ou administrador de storage.
* Você deve ter configurado as definições para criar cópias Snapshot no console de manutenção para identificar o destino onde as cópias Snapshot serão criadas.


As cópias Snapshot são criadas em apenas alguns minutos, e o banco de dados do Unified Manager fica bloqueado por apenas alguns segundos.

[NOTE]
====
O backup realizado durante os primeiros 15 dias após a adição de um novo cluster pode não ser preciso o suficiente para obter dados históricos de desempenho.

====
.Passos
. No painel de navegação esquerdo, clique em *Geral* > *backup do banco de dados*.
. Na página *Backup do Banco de Dados*, clique em *Configurações de Backup*.
. Insira o número máximo de cópias Snapshot que você deseja manter no campo *Retention Count*.
+
O valor padrão da contagem de retenção é 10. O número máximo de cópias Snapshot é determinado pela versão do software ONTAP no cluster. Você pode deixar este campo em branco para implementar o valor máximo independentemente da versão do ONTAP.

. Selecione o botão *Agendado Diariamente* ou *Agendado Semanalmente* e em seguida especifique os detalhes do agendamento.
. Clique em *Aplicar*.


As cópias Snapshot são criadas com base no agendamento. Você pode ver os arquivos de backup disponíveis na página Database Backup.

Devido à importância deste volume e dos Snapshots, você pode criar um ou dois alertas para este volume para receber uma notificação quando ocorrer qualquer uma destas situações:

* O espaço do volume está 90% cheio. Use o evento *Espaço do volume cheio* para configurar o alerta.
+
Você pode adicionar capacidade ao volume usando o ONTAP System Manager ou a ONTAP CLI para que o banco de dados do Unified Manager não fique sem espaço.

* O número de snapshots está próximo de atingir o número máximo. Use o evento *Too Many Snapshot Copies* para configurar o alerta.
+
Você pode excluir snapshots mais antigos usando o ONTAP System Manager ou a ONTAP CLI para que sempre haja espaço para novas cópias Snapshot.



Você configura os alertas na página Configuração de Alertas.
