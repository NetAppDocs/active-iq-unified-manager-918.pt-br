= Restaurar um backup de banco de dados MySQL em um sistema Linux no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Se ocorrer perda de dados ou corrupção de dados, você poderá restaurar o Unified Manager ao estado estável anterior com perda mínima de dados. Você pode restaurar o banco de dados do Unified Manager em um sistema local ou remoto Red Hat Enterprise Linux usando o console de manutenção do Unified Manager.

.Antes de começar
* Você precisa ter as credenciais do usuário raiz para o host Linux no qual o Unified Manager está instalado.
* Você precisa ter um ID de usuário e uma senha autorizados para fazer login no console de manutenção do servidor Unified Manager.
* Você deve ter copiado o arquivo de backup do Unified Manager e o conteúdo do diretório do repositório do banco de dados para o sistema no qual realizará a operação de restauração.
+
Recomenda-se que você copie o arquivo de backup para o diretório padrão /`data/ocum`-backup. Os arquivos do repositório do banco de dados devem ser copiados para o subdiretório /`database-dumps-repo` no diretório /`ocum-backup`.

* Os arquivos de backup devem ser do tipo `.7z`.


O recurso de restauração é específico da plataforma e da versão. Você pode restaurar um backup do Unified Manager somente na mesma versão do Unified Manager. Você pode restaurar um arquivo de backup do Linux ou um arquivo de backup de appliance virtual para um sistema Red Hat Enterprise Linux.

[TIP]
====
Se o nome da pasta de backup contiver um espaço, você deverá incluir o caminho absoluto ou relativo entre aspas duplas.

====
.Passos
. Se você estiver realizando uma restauração em um novo servidor, após instalar o Unified Manager, não inicie a UI nem configure clusters, usuários ou configurações de autenticação quando a instalação estiver concluída. O arquivo de backup preenche essas informações durante o processo de restauração.
. Usando o Secure Shell, conecte-se ao endereço IP ou ao nome de domínio totalmente qualificado do sistema Unified Manager.
. Faça login no sistema com o nome e a senha do usuário de manutenção (umadmin).
. Digite o comando `maintenance_console` e pressione Enter.
. No console de manutenção, no *Main Menu*, insira o número da opção *Backup Restore*.
. Digite o número para *Restore MySQL Backup*.
. Quando solicitado, insira o caminho absoluto do arquivo de backup.
+
[listing]
----
Bundle to restore from: /data/ocum-backup/UM_9.8.N151113.1348_backup_rhel_02-20-2020-04-45.7z
----
+
Após a conclusão da operação de restauração, você poderá fazer login no Unified Manager.



Após restaurar o backup, se o servidor do OnCommand Workflow Automation não funcionar, execute as seguintes etapas:

. No servidor do Workflow Automation, altere o endereço IP do servidor do Unified Manager para apontar para a máquina mais recente.
. No servidor do Unified Manager, redefina a senha do banco de dados se a aquisição falhar na etapa 1.
