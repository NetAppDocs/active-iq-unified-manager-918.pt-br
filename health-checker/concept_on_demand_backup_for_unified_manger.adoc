= Entenda o backup sob demanda para o Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode usar a interface de usuário do Active IQ Unified Manager para gerar backup sob demanda sempre que necessário. O backup sob demanda permite que você crie instantaneamente um backup usando o método de backup existente. O backup sob demanda não diferencia entre backup baseado em MySQL ou em Snapshot da NetApp.

Você pode realizar backup sob demanda usando o botão *Backup Now* na página Backup do banco de dados. O backup sob demanda não depende dos agendamentos que você configurou para o Active IQ Unified Manager.
