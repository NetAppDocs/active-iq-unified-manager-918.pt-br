= Adicionar grupos no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode criar grupos para combinar clusters, volumes e máquinas virtuais de armazenamento (SVMs) para facilitar o gerenciamento.

.Antes de começar
Você precisa ter a função de Application Administrator ou Storage Administrator.

Você pode definir regras de grupo para adicionar ou remover membros do grupo e para modificar as ações de grupo do grupo.

.Passos
. No painel de navegação esquerdo, clique em *Gerenciamento de armazenamento* > *Grupos*.
. Na aba *Grupos*, clique em *Adicionar*.
. Na caixa de diálogo *Adicionar Grupo*, insira um nome e uma descrição para o grupo.
. Clique em *Add*.
