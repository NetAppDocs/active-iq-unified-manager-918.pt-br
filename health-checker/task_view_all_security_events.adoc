= Visualize todos os eventos de segurança ativos no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode visualizar todos os eventos de segurança ativos e, em seguida, atribuir cada um deles a um usuário que possa resolver o problema. Além disso, se houver determinados eventos de segurança que você não deseja receber, esta lista pode ajudar você a identificar os eventos que deseja desativar.

.Antes de começar
Você precisa ter a função de Operador, Administrador de Aplicativos ou administrador de storage.

.Passos
. No painel de navegação à esquerda, clique em *Event Management*.
+
Por padrão, os eventos Novos e Reconhecidos são exibidos na página de inventário de gerenciamento de eventos.

. No menu Exibir, selecione *eventos de segurança ativos*.
+
A página exibe todos os eventos de segurança novos e reconhecidos gerados nos últimos 7 dias.
