= Saiba mais sobre os eventos Bridge do MetroCluster no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Os eventos de bridge do MetroCluster fornecem informações sobre o status das bridges, permitindo que você monitore possíveis problemas em uma configuração MetroCluster over FC. Os eventos são agrupados por área de impacto e incluem o nome do evento e do trap, o nível de impacto, o tipo de origem e a gravidade.
