= Saiba mais sobre eventos de VMs de armazenamento no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Os eventos de máquina virtual de armazenamento (storage virtual machine, também conhecida como SVM) fornecem informações sobre o status das suas máquinas virtuais de armazenamento (SVMs), permitindo que você monitore possíveis problemas. Os eventos são agrupados por área de impacto e incluem o nome do evento e do trap, o nível de impacto, o tipo de origem e a gravidade.

Um asterisco (*) identifica eventos do EMS que foram convertidos em eventos do Unified Manager.
