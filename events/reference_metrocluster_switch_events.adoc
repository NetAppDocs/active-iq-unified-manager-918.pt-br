= Saiba mais sobre os eventos de switch do MetroCluster no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Os eventos de switch do MetroCluster para configurações MetroCluster over FC fornecem informações sobre o status dos switches do MetroCluster, para que você possa monitorar possíveis problemas. Os eventos são agrupados por área de impacto e incluem o nome do evento e do trap, o nível de impacto, o tipo de origem e a gravidade.
