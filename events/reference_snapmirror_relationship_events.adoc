= Saiba mais sobre eventos de relação do SnapMirror no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Os eventos de relação do SnapMirror fornecem informações sobre o status das suas relações assíncronas e síncronas do SnapMirror, para que você possa monitorar possíveis problemas. Os eventos de relação assíncrona do SnapMirror são gerados tanto para Storage VMs quanto para volumes, mas os eventos de relação síncrona do SnapMirror são gerados apenas para relações de volume. Não há eventos gerados para volumes constituintes que fazem parte de relações de recuperação de desastres de Storage VM. Os eventos são agrupados por área de impacto e incluem o nome do evento e do trap, o nível de impacto, o tipo de origem e a gravidade.



[[impact-area-protection]]
== Área de impacto: proteção

Um asterisco (*) identifica eventos do EMS que foram convertidos em eventos do Unified Manager.

[NOTE]
====
Os eventos de relacionamentos do SnapMirror são gerados para máquinas virtuais de armazenamento protegidas pela recuperação de desastres de máquina virtual de armazenamento, mas não para relacionamentos de objetos constituintes.
