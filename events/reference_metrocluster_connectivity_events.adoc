= Saiba mais sobre os eventos de conectividade do MetroCluster no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Os eventos de conectividade fornecem informações sobre a conectividade entre os componentes de um cluster e entre clusters em configurações MetroCluster over FC e MetroCluster over IP, para que você possa monitorar possíveis problemas. Os eventos são agrupados por área de impacto e incluem o nome do evento e do trap, o nível de impacto, o tipo de origem e a gravidade.



[[events-common-in-both-configurations]]
