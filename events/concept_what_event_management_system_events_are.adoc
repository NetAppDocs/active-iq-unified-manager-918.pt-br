= Saiba mais sobre eventos do Sistema de Gerenciamento de Eventos no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
O Sistema de Gerenciamento de Eventos (EMS) coleta dados de eventos de diferentes partes do kernel do ONTAP e fornece mecanismos de encaminhamento de eventos. Esses eventos do ONTAP podem ser relatados como eventos do EMS no Unified Manager. O monitoramento e o gerenciamento centralizados facilitam a configuração de eventos críticos do EMS e notificações de alerta com base nesses eventos.

O endereço do Unified Manager é adicionado como destino de notificação ao cluster quando você adiciona o cluster ao Unified Manager. Um evento do EMS é relatado assim que o evento ocorre no cluster.

Existem dois métodos para receber eventos EMS no Unified Manager:

* Um certo número de eventos importantes do EMS é relatado automaticamente.
* Você pode se inscrever para receber eventos individuais do EMS.


Os eventos do EMS gerados pelo Unified Manager são relatados de forma diferente dependendo do método utilizado para sua geração:

| Funcionalidade | Mensagens EMS automáticas | Mensagens EMS assinadas

[NOTE]
====
Alguns dos novos eventos automáticos do EMS são eventos informativos que indicam que um evento anterior foi resolvido. Por exemplo, o evento informativo "FlexGroup Constituents Space Status All OK" indica que o evento de erro "FlexGroup Constituents Have Space Issues" foi resolvido. Os eventos informativos não podem ser gerenciados usando o mesmo ciclo de vida de eventos que outros tipos de gravidade de eventos, no entanto, o evento se torna obsoleto automaticamente se o mesmo volume receber outro evento de erro "`Space Issues`".
