= Saiba mais sobre a caixa de diálogo Adicionar Alerta no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode criar alertas para ser notificado quando um evento específico for gerado, permitindo que você resolva o problema rapidamente e, assim, minimize o impacto em seu ambiente. Você pode criar alertas para um único recurso ou um conjunto de recursos, e para eventos de um determinado tipo de gravidade. Você também pode especificar o método de notificação e a frequência dos alertas.

Você precisa ter a função de Application Administrator ou Storage Administrator.



[[name]]
== Nome

Esta área permite que você especifique um nome e uma descrição para o alerta:

* *Nome do alerta*
+
Permite que você especifique um nome para o alerta.

* *Descrição do alerta*
+
Permite especificar uma descrição para o alerta.





[[resources]]
== Recursos

Esta área permite que você selecione um recurso individual ou agrupe os recursos com base em uma regra dinâmica para a qual você quer acionar o alerta. Uma regra dinâmica é o conjunto de recursos filtrados com base na cadeia de texto que você especificar. Você pode pesquisar recursos selecionando um tipo de recurso na lista suspensa ou pode especificar o nome exato do recurso para exibir um recurso específico.

Se você estiver criando um alerta a partir de qualquer uma das páginas de detalhes do objeto de armazenamento, o objeto de armazenamento será incluído automaticamente no alerta.

* *Incluir*
+
Permite incluir os recursos para os quais você deseja acionar alertas. Você pode especificar uma cadeia de texto para agrupar recursos que correspondam à cadeia e selecionar esse grupo para incluí-lo no alerta. Por exemplo, você pode agrupar todos os volumes cujo nome contenha a cadeia "abc".

* *Excluir*
+
Permite excluir recursos para os quais você não deseja acionar alertas. Por exemplo, você pode excluir todos os volumes cujo nome contenha a cadeia de texto "xyz".

+
A guia Excluir é exibida somente quando você seleciona todos os recursos de um determinado tipo de recurso: por exemplo, +<<All Volumes>> ou <<All Volumes whose name contains 'xyz'>>+.

+
Se um recurso estiver em conformidade com as regras de inclusão e exclusão que você especificou, a regra de exclusão terá precedência sobre a regra de inclusão, e o alerta não será gerado para o evento.





[[events]]
== Eventos

Esta área permite selecionar os eventos para os quais você deseja criar alertas. Você pode criar alertas para eventos com base em uma determinada gravidade ou para um conjunto de eventos.

Para selecionar mais de um evento, você deve manter pressionada a tecla Ctrl enquanto faz suas seleções.

* *Gravidade do evento*
+
Permite selecionar eventos com base no tipo de gravidade, que pode ser Crítica, Erro ou Aviso.

* *O nome do evento contém*
+
Permite selecionar eventos cujos nomes contenham os caracteres especificados.





[[actions]]
== Ações

Esta área permite que você especifique os usuários que deseja notificar quando um alerta for acionado. Você também pode especificar o método de notificação e a frequência das notificações.

* *Avise esses usuários*
+
Permite que você especifique o endereço de e-mail ou o nome de usuário do usuário para receber notificações.

+
Se você modificar o endereço de e-mail especificado para o usuário e reabrir o alerta para edição, o campo Name aparecerá em branco, pois o endereço de e-mail modificado não estará mais vinculado ao usuário que foi selecionado anteriormente. Além disso, se você tiver modificado o endereço de e-mail do usuário selecionado na página Users, o endereço de e-mail modificado não será atualizado para o usuário selecionado.

* *Frequência de notificação*
+
Permite que você especifique a frequência com que o servidor de gerenciamento envia notificações até que o evento seja reconhecido, resolvido ou movido para o estado obsoleto.

+
Você pode escolher os seguintes métodos de notificação:

+
** Notificar apenas uma vez
** Notificar com uma frequência específica
** Notificar com a frequência especificada dentro do intervalo de tempo especificado


* *Emitir trap SNMP*
+
Ao selecionar esta caixa, você pode especificar se os traps SNMP devem ser enviados para o host SNMP configurado globalmente.

* *Executar Script*
+
Permite que você adicione seu script personalizado ao alerta. Esse script é executado quando um alerta é gerado.

+
[NOTE]
====
Se você não visualizar essa funcionalidade na interface de usuário, é porque seu administrador a desativou. Se necessário, você pode ativá-la em *Gerenciamento de Armazenamento* > *Configurações de recursos*.

====




[[command-buttons]]
== Botões de comando

* *Salvar*
+
Cria um alerta e fecha a caixa de diálogo.

* *Cancelar*
+
Descarta as alterações e fecha a caixa de diálogo.
