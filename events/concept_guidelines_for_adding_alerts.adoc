= Diretrizes para adicionar alertas no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode adicionar alertas com base em um recurso, como um cluster, nó, agregado ou volume, e em eventos de um tipo de gravidade específico. Como prática recomendada, você pode adicionar um alerta para qualquer um dos seus objetos críticos depois de ter adicionado o cluster ao qual o objeto pertence.

Você pode usar as seguintes diretrizes e considerações para criar alertas para gerenciar seus sistemas com eficácia:

* Descrição do alerta
+
Você deve fornecer uma descrição para o alerta para que isso ajude você a rastrear seus alertas com eficácia.

* Recursos
+
Você deve decidir qual recurso físico ou lógico requer um alerta. Você pode incluir e excluir recursos, conforme necessário. Por exemplo, se você deseja monitorar de perto seus agregados configurando um alerta, você deve selecionar os agregados necessários na lista de recursos.

+
Se você selecionar uma categoria de recursos, por exemplo, *+<<All User or Group Quotas>>+*, você receberá alertas para todos os objetos dessa categoria.

+
[NOTE]
====
Selecionar um cluster como recurso não seleciona automaticamente os objetos de armazenamento dentro desse cluster. Por exemplo, se você criar um alerta para todos os eventos críticos em todos os clusters, receberá alertas apenas para eventos críticos do cluster. Você não receberá alertas para eventos críticos em nós, agregados e assim por diante.

====
* Gravidade do evento
+
Você deve decidir se um evento de um tipo de gravidade especificado (Crítico, Erro, Aviso) deve acionar o alerta e, em caso afirmativo, qual tipo de gravidade.

* Eventos selecionados
+
Se você adicionar um alerta com base no tipo de evento gerado, deve decidir quais eventos exigem um alerta.

+
Se você selecionar uma gravidade do evento, mas não selecionar nenhum evento individual (se deixar a coluna "Eventos Selecionados" vazia), você receberá alertas para todos os eventos da categoria.

* Ações
+
Você deve fornecer os nomes de usuário e endereços de e-mail dos usuários que receberão a notificação. Você também pode especificar um trap SNMP como modo de notificação. Você pode associar seus scripts a um alerta para que eles sejam executados quando um alerta for gerado.

* Frequência de notificação
+
Você pode configurar um alerta para enviar uma notificação repetidamente aos destinatários durante um período específico. Você deve determinar a partir de que horário a notificação do evento ficará ativa para o alerta. Se você quiser que a notificação do evento seja repetida até que o evento seja confirmado, deverá determinar com que frequência a notificação será repetida.

* Executar script
+
Você pode associar seu script a um alerta. Seu script é executado quando o alerta é gerado.
