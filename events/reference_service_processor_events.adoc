= Saiba mais sobre os eventos do Service Processor no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Os eventos do processador de serviço fornecem informações sobre o status do seu processador para que você possa monitorar possíveis problemas. Os eventos são agrupados por área de impacto e incluem o nome do evento e da armadilha, o nível de impacto, o tipo de origem e a gravidade.
