= Editar propriedades de alerta no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode editar as propriedades do alerta, como o recurso ao qual o alerta está associado, os eventos, o script e as opções de notificação.



[[name]]
== Nome

Esta área permite editar o nome e a descrição do alerta.

* *Nome do alerta*
+
Permite editar o nome do alerta.

* *Descrição do alerta*
+
Permite especificar uma descrição para o alerta.

* *Estado de alerta*
+
Permite que você ative ou desative o alerta.





[[resources]]
== Recursos

Esta área permite selecionar um recurso individual ou agrupar os recursos com base em uma regra dinâmica para a qual você deseja acionar o alerta. Você pode pesquisar recursos selecionando um tipo de recurso na lista suspensa ou especificar o nome exato do recurso para exibir um recurso específico.

* *Incluir*
+
Permite incluir os recursos para os quais você deseja acionar alertas. Você pode especificar uma cadeia de texto para agrupar recursos que correspondam a ela e selecionar esse grupo para incluí-lo no alerta. Por exemplo, você pode agrupar todos os volumes cujo nome contenha a sequência "`vol0`".

* *Excluir*
+
Permite excluir recursos para os quais você não deseja acionar alertas. Por exemplo, você pode excluir todos os volumes cujo nome contenha a string "`xyz`".

+
[NOTE]
====
A guia Exclude é exibida somente quando você seleciona todos os recursos de um determinado tipo de recurso, por exemplo, +<<All Volumes>>+ ou +<<All Volumes whose name contains 'xyz'>>+.

====




[[events]]
== Eventos

Esta área permite selecionar os eventos para os quais você deseja acionar os alertas. Você pode acionar um alerta para eventos com base em uma determinada gravidade ou para um conjunto de eventos.

* *Gravidade do evento*
+
Permite selecionar eventos com base no tipo de gravidade, que pode ser Crítica, Erro ou Aviso.

* *O nome do evento contém*
+
Permite selecionar eventos cujos nomes contenham os caracteres especificados.





[[actions]]
== Ações

Esta área permite que você especifique o método de notificação e a frequência da notificação.

* *Avise esses usuários*
+
Permite editar o endereço de e-mail ou o nome de usuário, ou especificar um novo endereço de e-mail ou nome de usuário para receber notificações.

* *Frequência de notificação*
+
Permite editar a frequência com que o servidor de gerenciamento envia notificações até que o evento seja reconhecido, resolvido ou movido para o estado obsoleto.

+
Você pode escolher os seguintes métodos de notificação:

+
** Notificar apenas uma vez
** Notificar com uma frequência específica
** Notificar com a frequência especificada dentro do intervalo de tempo especificado


* *Emitir trap SNMP*
+
Permite que você especifique se as traps SNMP devem ser enviadas ao host SNMP configurado globalmente.

* *Executar Script*
+
Permite que você associe um script ao alerta. Esse script é executado quando um alerta é gerado.





[[command-buttons]]
== Botões de comando

* *Salvar*
+
Salva as alterações e fecha a caixa de diálogo.

* *Cancelar*
+
Descarta as alterações e fecha a caixa de diálogo.
