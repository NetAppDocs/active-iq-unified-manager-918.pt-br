= Saiba mais sobre a página de Notificações em o Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode configurar o servidor do Unified Manager para enviar notificações quando um evento for gerado ou quando for atribuído a um usuário. Você também pode configurar os mecanismos de notificação. Por exemplo, as notificações podem ser enviadas como e-mails ou traps SNMP.

Você precisa ter a função de Application Administrator ou Storage Administrator.



[[email]]
== E-mail

Esta área permite que você configure as seguintes configurações de email para notificação de alerta:

* *Endereço do remetente*
+
Especifica o endereço de e-mail do qual a notificação de alerta é enviada. Esse valor também é usado como endereço de remetente de um relatório quando ele é compartilhado. Se o endereço de remetente estiver preenchido automaticamente com "ActiveIQUnifiedManager@localhost.com", você deve alterá-lo para um endereço de e-mail real e válido para garantir que todas as notificações por e-mail sejam entregues com sucesso.





[[smtp-server]]
== Servidor SMTP

Esta área permite configurar as seguintes definições do servidor SMTP:

* *Nome do host ou endereço IP*
+
Especifica o nome do host do seu servidor SMTP, que será usado para enviar a notificação de alerta aos destinatários especificados.

* *Nome de usuário*
+
Especifica o nome de usuário SMTP. O nome de usuário SMTP é necessário apenas quando o SMTPAUTH está habilitado no servidor SMTP.

* *Senha*
+
Especifica a senha SMTP. O nome de usuário SMTP é necessário apenas quando o SMTPAUTH está habilitado no servidor SMTP.

* *Porta*
+
Especifica a porta usada pelo servidor host SMTP para enviar notificações de alerta.

+
O valor padrão é 25.

* *Usar START/TLS*
+
Marcar esta caixa permite a comunicação segura entre o servidor SMTP e o servidor de gerenciamento utilizando os protocolos TLS/SSL (também conhecidos como start_tls e StartTLS).

* *Usar SSL*
+
Marcar esta caixa permite a comunicação segura entre o servidor SMTP e o servidor de gerenciamento utilizando o protocolo SSL.





[[snmp]]
== SNMP

Esta área permite configurar as seguintes configurações de trap SNMP:

* *Versão*
+
Especifica a versão SNMP que você deseja usar, dependendo do tipo de segurança necessário. As opções incluem Versão 1, Versão 3, Versão 3 com Autenticação e Versão 3 com Autenticação e Criptografia. O valor padrão é Versão 1.

* *Host de destino da trap*
+
Especifica o nome do host ou endereço IP (IPv4 ou IPv6) que receberá os traps SNMP enviados pelo servidor de gerenciamento. Para especificar vários destinos de trap, separe cada host com uma vírgula.

+
[NOTE]
====
Todas as outras configurações SNMP, como "Versão" e "Porta de saída", devem ser as mesmas para todos os hosts da lista.

====
* *Porta de trap de saída*
+
Especifica a porta através da qual o servidor SNMP recebe os traps enviados pelo servidor de gerenciamento.

+
O valor padrão é 162.

* *Comunidade*
+
A string de comunidade para acessar o host.

* *ID do mecanismo*
+
Especifica o identificador exclusivo do agente SNMP e é gerado automaticamente pelo servidor de gerenciamento. O Engine ID está disponível com SNMP Version 3, SNMP Version 3 with Authentication e SNMP Version 3 with Authentication and Encryption.

* *Nome de usuário*
+
Especifica o nome de usuário SNMP. O nome de usuário está disponível na versão 3 do SNMP, na versão 3 do SNMP com autenticação e na versão 3 do SNMP com autenticação e criptografia.

* *Protocolo de Autenticação*
+
Especifica o protocolo usado para autenticar um usuário. As opções de protocolo incluem MD5 e SHA. MD5 é o valor padrão. O protocolo de autenticação está disponível com SNMP versão 3 com autenticação e SNMP versão 3 com autenticação e criptografia.

* *Senha de autenticação*
+
Especifica a senha usada ao autenticar um usuário. A senha de autenticação está disponível no SNMP versão 3 com autenticação e no SNMP versão 3 com autenticação e criptografia.

* *Protocolo de Privacidade*
+
Especifica o protocolo de privacidade usado para criptografar mensagens SNMP. As opções de protocolo incluem AES 128 e DES. O valor padrão é AES 128. O protocolo de privacidade está disponível na versão 3 do SNMP com autenticação e criptografia.

* *Senha de privacidade*
+
Especifica a senha ao usar o protocolo de privacidade. A senha de privacidade está disponível com a versão 3 do SNMP com autenticação e criptografia.



Para obter mais informações sobre objetos e traps SNMP, você pode baixar o link:https://mysupport.netapp.com/site/tools/tool-eula/aiqum-mib["MIB do Active IQ Unified Manager"^] no site de suporte da NetApp.
