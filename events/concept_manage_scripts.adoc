= Gerencie scripts no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode usar scripts para modificar ou atualizar automaticamente vários objetos de armazenamento no Unified Manager. O script está associado a um alerta. Quando um evento aciona um alerta, o script é executado. Você pode carregar scripts personalizados e testar sua execução quando um alerta é gerado.

A capacidade de carregar scripts no Unified Manager e executá-los está habilitada por padrão. Se sua organização não quiser permitir essa funcionalidade por motivos de segurança, você pode desativá-la em *Storage Management* > *Feature Settings*.
