= Saiba mais sobre eventos de namespace NVMe no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Os eventos de namespace NVMe fornecem informações sobre o status dos seus namespaces, permitindo que você monitore possíveis problemas. Os eventos são agrupados por área de impacto e incluem o nome do evento e do trap, o nível de impacto, o tipo de origem e a gravidade.

Um asterisco (*) identifica eventos do EMS que foram convertidos em eventos do Unified Manager.
