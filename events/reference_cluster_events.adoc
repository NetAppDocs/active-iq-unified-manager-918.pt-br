= Saiba mais sobre eventos em cluster no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Os eventos de cluster fornecem informações sobre o status dos clusters, permitindo que você os monitore em busca de possíveis problemas. Os eventos são agrupados por área de impacto e incluem o nome do evento, o nome do trap, o nível de impacto, o tipo de origem e a gravidade.
