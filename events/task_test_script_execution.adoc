= Execução de script de teste no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode verificar se seu script é executado corretamente quando um alerta é gerado para um objeto de armazenamento.

.Antes de começar
* Você precisa ter a função de Application Administrator ou Storage Administrator.
* Você deve ter carregado no Unified Manager um script em um formato de arquivo compatível.


.Passos
. No painel de navegação esquerdo, clique em *Gerenciamento de armazenamento* > *Scripts*.
. Na página *Scripts*, adicione seu script de teste.
. No painel de navegação à esquerda, clique em *Gerenciamento de armazenamento* > *Configuração de alertas*.
. Na página *Configuração de alertas*, execute uma das seguintes ações:
+
|===
| Para... | Faça isso... 


 a| 
Adicionar um alerta
 a| 
.. Clique em *Add*.
.. Na seção Ações, associe o alerta ao seu script de teste.




 a| 
Editar um alerta
 a| 
.. Selecione um alerta e clique em *Editar*.
.. Na seção Ações, associe o alerta ao seu script de teste.


|===
. Clique em *Salvar*.
. Na página *Alert Setup*, selecione o alerta que você adicionou ou modificou e clique em *Test*.
+
O script é executado com o argumento "-test", e um alerta de notificação é enviado para os endereços de e-mail que foram especificados quando o alerta foi criado.
