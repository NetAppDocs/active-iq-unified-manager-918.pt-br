= Configure uma conexão entre o OnCommand Workflow Automation e o Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode configurar uma conexão segura entre o OnCommand Workflow Automation (WFA) e o Unified Manager. A conexão com o Workflow Automation permite que você use recursos de proteção, como fluxos de trabalho de configuração do SnapMirror e do SnapVault, além de comandos para gerenciar relacionamentos do SnapMirror.

.Antes de começar
* A versão instalada do Workflow Automation deve ser 5.1.1P6 ou superior.
+
[NOTE]
====
O pacote "WFA para gerenciamento de Clustered Data ONTAP" está incluído no WFA 5.1.1P6, portanto, não é necessário baixar este pacote da NetAppStorage Automation Store e instalá-lo separadamente em seu servidor WFA, como era necessário anteriormente. https://mysupport.netapp.com/site/products/all/details/ocwfa/downloads-tab["Download WFA"^]

====
* Você precisa ter o nome do usuário do banco de dados que você criou no Unified Manager para dar suporte às conexões do WFA e do Unified Manager.
+
Este usuário do banco de dados deve ter recebido a função de usuário Integration Schema.

* Você precisa ter a função de Administrador ou a função de Arquiteto atribuída no Workflow Automation.
* Você precisa ter o endereço do host, o número da porta 443, o nome de usuário e a senha para a configuração do Workflow Automation.
* Você precisa ter a função de Application Administrator ou Storage Administrator.


.Passos
. No painel de navegação esquerdo, clique em *General* > *Workflow Automation*.
. Na área *Usuário do Banco de Dados* da *página do Workflow Automation*, selecione o nome e insira a senha do usuário do banco de dados que você criou para dar suporte às conexões do Unified Manager e do Workflow Automation.
. Na área *Workflow Automation Credentials* da página, insira o nome do host ou o endereço IP (IPv4 ou IPv6), bem como o nome de usuário e a senha para a configuração do Workflow Automation.
+
Você deve usar a porta do servidor do Unified Manager (porta 443).

. Clique em *Salvar*.
. Se você usar um certificado autoassinado, clique em *Sim* para autorizar o certificado de segurança.
+
A página Workflow Automation é exibida.

. Clique em *Sim* para recarregar a IU da web, e adicionar os recursos do Workflow Automation.
