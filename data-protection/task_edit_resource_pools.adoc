= Editar pools de recursos no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode editar um pool de recursos existente quando quiser alterar o nome e a descrição do pool de recursos.

.Antes de começar
Você precisa ter a função de Application Administrator ou Storage Administrator.

O botão *Editar* só fica habilitado quando um pool de recursos é selecionado. Se mais de um pool de recursos for selecionado, o botão *Editar* fica desabilitado.

.Passos
. No painel de navegação esquerdo, clique em *Proteção* > *Pools de recursos*.
. Selecione um pool de recursos da lista.
. Clique em *Editar*.
+
A janela Editar Pool de Recursos é exibida.

. Edite o nome e a descrição do pool de recursos conforme necessário.
. Clique em *Salvar*.
+
O novo nome e a descrição são exibidos na lista de pools de recursos.
