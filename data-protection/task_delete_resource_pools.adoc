= Excluir pools de recursos no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode excluir pools de recursos quando eles não forem mais necessários. Por exemplo, você pode querer redistribuir os agregados membro de um pool de recursos para vários outros pools de recursos, tornando obsoleto o pool de recursos original.

.Antes de começar
Você precisa ter a função de Application Administrator ou Storage Administrator.

O botão *Excluir* só fica habilitado quando pelo menos um pool de recursos é selecionado.

.Passos
. No painel de navegação esquerdo, clique em *Proteção* > *Pools de recursos*.
. Selecione o pool de recursos que você deseja excluir.
. Clique em *Delete*.
+
O pool de recursos é removido da lista de pools de recursos, e seus agregados são removidos da lista de membros.
