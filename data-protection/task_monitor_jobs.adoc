= Monitore tarefas no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode usar a página Jobs para monitorar o status da tarefa e visualizar propriedades da tarefa, como tipo de serviço de armazenamento, estado, horário de envio e horário de conclusão, para determinar se uma tarefa foi concluída com sucesso.

.Antes de começar
Você precisa ter a função de Application Administrator ou Storage Administrator.

.Passos
. No painel de navegação esquerdo, clique em *Proteção* > *Tarefas*.
+
A página Jobs é exibida.

. Consulte a coluna *Estado* para determinar o status dos trabalhos em execução no momento.
. Clique no nome de uma tarefa para ver detalhes sobre essa tarefa específica.
+
A página de detalhes do trabalho é exibida.
