= Crie pools de recursos no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode usar a caixa de diálogo Criar pool de recursos para agrupar agregados para fins de provisionamento.

.Antes de começar
Você precisa ter a função de Application Administrator ou Storage Administrator.

.Passos
Os pools de recursos podem conter agregados de diferentes clusters, mas o mesmo agregado não pode pertencer a diferentes pools de recursos.

. No painel de navegação esquerdo, clique em *Proteção* > *Pools de recursos*.
. Na página *Pool de recursos*, clique em *Criar*.
. Siga as instruções na caixa de diálogo *Criar pool de recursos* para fornecer um nome e uma descrição e adicionar agregados como membros ao pool de recursos que você deseja criar.
