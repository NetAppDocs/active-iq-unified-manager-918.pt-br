= Personalizando o layout da janela no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
O Active IQ Unified Manager permite personalizar o layout das informações nas páginas de objetos de armazenamento e rede. Ao personalizar as janelas, você pode controlar quais dados são visíveis e como eles são exibidos.

* *Ordenação*
+
Você pode clicar no cabeçalho da coluna para alterar a ordem de classificação das entradas da coluna. Ao clicar no cabeçalho da coluna, as setas de classificação (image:../media/sort_asc_um60.gif["Ícone para ordenação crescente de colunas"] e image:../media/sort_desc_um60.gif["Ícone para ordenação de colunas em ordem decrescente"]) aparecem para essa coluna.

* *Filtragem*
+
Você pode clicar no ícone de filtro (image:../media/filtering_icon.gif[""]) para aplicar filtros e personalizar a exibição de informações nas páginas de objetos de armazenamento e rede, de forma que apenas as entradas que correspondam às condições fornecidas sejam exibidas. Você aplica os filtros no painel Filtros.

+
O painel Filtros permite filtrar a maioria das colunas com base nas opções selecionadas. Por exemplo, na visualização Saúde: todos os volumes, você pode usar o painel Filtros para exibir todos os volumes que estão offline selecionando a opção de filtro apropriada em Estado.

+
As colunas relacionadas à capacidade em qualquer lista sempre exibem os dados de capacidade nas unidades apropriadas, arredondados para duas casas decimais. Isso também se aplica ao filtrar colunas de capacidade. Por exemplo, se você usar o filtro na coluna Total Data Capacity na visualização Health: All Aggregates para filtrar dados maiores que 20.45 GB, a capacidade real de 20.454 GB é exibida como 20.45 GB. Da mesma forma, se você filtrar dados menores que 20.45 GB, a capacidade real de 20.449 GB é exibida como 20.45 GB.

+
Se você usar o filtro na coluna "Available Data %" na visualização "Health: All Aggregates" para filtrar dados maiores que 20.45%, a capacidade real de 20.454% será exibida como 20.45%. Da mesma forma, se você filtrar dados menores que 20.45%, a capacidade real de 20.449% será exibida como 20.45%.

* *Ocultar ou exibir as colunas*
+
Você pode clicar no ícone de exibição de colunas (*Mostrar/Ocultar*) para selecionar quais colunas deseja exibir. Depois de selecionar as colunas desejadas, você pode reordená-las arrastando-as com o mouse.

* *Buscando*
+
Você pode usar a caixa de pesquisa para buscar determinados atributos de objetos e ajudar a refinar a lista de itens na página de inventário. Por exemplo, você pode digitar "cloud" para refinar a lista de volumes na página de inventário de volumes e ver todos os volumes que contêm a palavra "cloud".

* *Exportando dados*
+
Você pode clicar no botão *Reports* (ou no botão *Export* para exportar dados para um arquivo `(.csv)` de valores separados por vírgulas, `(.pdf)` documento ou arquivo do Microsoft Excel `(.xlsx)` e usar os dados exportados para criar relatórios.
