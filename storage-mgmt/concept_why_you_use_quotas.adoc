= Saiba mais sobre cotas no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode usar cotas para limitar o uso de recursos em volumes FlexVol, para fornecer notificações quando o uso de recursos atingir níveis específicos ou para monitorar o uso de recursos.

Você especifica uma cota pelos seguintes motivos:

* Para limitar a quantidade de espaço de disco ou o número de arquivos que podem ser usados por um usuário ou grupo, ou que uma qtree pode conter
* Para monitorar a quantidade de espaço de disco ou o número de arquivos usados por um usuário, grupo ou qtree, sem impor um limite
* Para alertar os usuários quando o uso de disco ou de arquivos estiver alto
