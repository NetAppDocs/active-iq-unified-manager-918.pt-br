= Remover clusters do Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode remover um cluster do Unified Manager usando a página Cluster Setup. Por exemplo, você pode remover um cluster se a descoberta do cluster falhar ou quando quiser desativar um sistema de storage.

.Antes de começar
Você precisa ter a função de Administrador de Aplicativos ou a função de Administrador de Armazenamento.

Esta tarefa remove o cluster selecionado do Unified Manager. Após a remoção, o cluster deixa de ser monitorado. A instância do Unified Manager registrada no cluster removido também é desregistrada do cluster.

A remoção de um cluster também exclui todos os seus objetos de storage, dados históricos, serviços de storage e todos os eventos associados do Unified Manager. Essas alterações aparecem nas páginas de inventário e nas páginas de detalhes após o próximo ciclo de coleta de dados.

[NOTE]
====
Você deve remover um cluster do Unified Manager antes de desativá-lo. Se o cluster já estiver offline ou inacessível quando você tentar removê-lo, o Unified Manager não poderá se comunicar com o cluster para remover o registro do aplicativo e as assinaturas do Event Management System (EMS) configuradas. Isso fará com que o processo de remoção falhe ou pare de responder antes da conclusão.

====
.Passos
. No painel de navegação esquerdo, clique em *Gerenciamento de armazenamento* > *Configuração de cluster*.
. Na página Cluster Setup, selecione o cluster que deseja remover e clique em *Remove*.
. Na caixa de diálogo *Remover Fonte de Dados*, clique em *Remover* para confirmar a solicitação de remoção.
