= Resolva um problema de rotação de logs do NetApp Manageability SDK no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Após adicionar um cluster baseado na API ONTAPI ao Unified Manager em um sistema operacional Windows, o  `nmsdk.log`tamanho do arquivo aumenta e ultrapassa o limite de 10 MB.

*Causa*

Esse problema pode ocorrer se a rotação de logs não ocorrer.

*Ação corretiva*

. Pare o Unified Manager.
. Ao instalar o Unified Manager no Windows, instale o Logrotate versão 0.0.0.18. Para obter mais informações, consulte o link:https://www.netapp.com/pdf.html?item=/media/78941-tr-4945.pdf["Guia de reforço de segurança para o relatório técnico do NetApp Manageability SDK"^].
. Inicie o Unified Manager.
