= Exporte os dados de armazenamento como relatórios no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode exportar dados de armazenamento em diversos formatos de saída e, em seguida, usar os dados exportados para criar relatórios. Por exemplo, se houver 10 eventos críticos que não foram resolvidos, você pode exportar os dados da página de inventário do Gerenciamento de Eventos para criar um relatório e, em seguida, enviar o relatório aos administradores que podem resolver os problemas.

Você pode exportar dados para um  `.csv`arquivo,  `.xlsx`arquivo ou  `.pdf`documento a partir das páginas de inventário *Armazenamento* e *Rede* e usar os dados exportados para criar relatórios. Existem outros locais no produto onde apenas `.csv` ou `.pdf` arquivos podem ser gerados.

.Passos
. Execute uma das seguintes ações:
+
|===
| Se você deseja exportar... | Faça isso... 


 a| 
Detalhes do inventário de objetos de storage
 a| 
Clique em *Storage* ou *Network* no menu de navegação à esquerda e selecione um objeto de storage. Escolha uma das visualizações fornecidas pelo sistema ou qualquer visualização personalizada que você tenha criado.



 a| 
Detalhes do grupo de políticas de QoS
 a| 
Clique em *Armazenamento* > *Grupos de Políticas de QoS* no menu de navegação à esquerda.



 a| 
Detalhes sobre a capacidade de armazenamento e o histórico de proteção
 a| 
Clique em *Armazenamento* > *Agregados* ou *Armazenamento* > *Volumes* e, em seguida, selecione um único agregado ou volume.



 a| 
Detalhes do evento
 a| 
Clique em *Event Management* no menu de navegação à esquerda.



 a| 
Detalhes de desempenho dos 10 principais objetos de armazenamento
 a| 
Clique em *Armazenamento* > *Clusters* > *Desempenho: Todos os Clusters*, selecione um cluster e escolha a guia *Melhores Desempenhos*. Em seguida, selecione um objeto de armazenamento e um contador de desempenho.

|===
. Clique no botão *Relatórios* (ou no botão *Exportar* em algumas páginas da interface de usuário).
. Clique em *Download CSV*, *Download PDF* ou *Download Excel* para confirmar a solicitação de exportação.
+
Na guia "Top Performers", você pode optar por baixar um relatório das estatísticas do cluster que está visualizando ou de todos os clusters do data center.

+
O arquivo foi baixado.

. Abra o arquivo no aplicativo adequado.
