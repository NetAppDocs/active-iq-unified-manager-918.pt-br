= Saiba mais sobre o MetroCluster por espelhamento de dados FC no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
As configurações do MetroCluster over FC oferecem espelhamento de dados e a capacidade adicional de iniciar um failover caso um site inteiro fique indisponível. O status do espelhamento de dados entre os clusters em uma configuração do MetroCluster over FC pode ser Normal ou Espelhamento indisponível. Entender o status permite que você gerencie suas configurações do MetroCluster com eficiência.

|===
| Status do espelhamento de dados | Descrição | Ícone exibido 


 a| 
Normal
 a| 
O espelhamento de dados entre os clusters na configuração do MetroCluster é normal.
 a| 
image:../media/metrocluster_connectivity_optimal.gif["ícone de conectividade ideal do MetroCluster"]



 a| 
Espelhamento indisponível
 a| 
O espelhamento de dados entre os clusters na configuração do MetroCluster está indisponível devido ao switchover. Por exemplo, quando o cluster parceiro está inativo devido a um desastre ou quando há um switchover planejado para fins de teste.
 a| 
Switchover com erros:

image::../media/metrocluster_connectivity_down.gif[ícone de conectividade do MetroCluster inativa]

Switchover concluído com sucesso:

image::../media/metrocluster_connectivity_failover.gif[ícone de failover de conectividade do metrocluster]

|===
