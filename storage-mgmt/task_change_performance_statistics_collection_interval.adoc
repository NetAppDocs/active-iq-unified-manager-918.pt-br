= Altere o intervalo de coleta de estatísticas de desempenho no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
O intervalo de coleta padrão para estatísticas é de 5 minutos. Você pode alterar esse intervalo para 10 ou 15 minutos se perceber que as coletas de clusters grandes não estão sendo concluídas dentro do tempo padrão. Essa configuração afeta a coleta de estatísticas de todos os clusters que esta instância do Unified Manager está monitorando.

.Antes de começar
Você precisa ter um ID de usuário e uma senha autorizados para fazer login no console de manutenção do servidor Unified Manager.

O problema de as coletas de estatísticas de desempenho não serem concluídas no prazo é indicado pelas mensagens no banner `Unable to consistently collect from cluster <cluster_name> or Data collection is taking too long on cluster <cluster_name>.`

Você deve alterar o intervalo de coleta somente quando necessário devido a um problema nas coletas de estatísticas. Não altere essa configuração por nenhum outro motivo.

[NOTE]
====
Alterar esse valor da configuração padrão de 5 minutos pode afetar o número e a frequência de eventos de desempenho que o Unified Manager relata. Por exemplo, os limites de desempenho definidos pelo sistema acionam eventos quando a política é excedida por 30 minutos. Ao usar coletas a cada 5 minutos, a política deve ser excedida por seis coletas consecutivas. Para coletas a cada 15 minutos, a política deve ser excedida por apenas dois períodos de coleta.

====
Uma mensagem na parte inferior da página de Configuração do Cluster indica o intervalo atual de coleta de dados estatísticos.

.Passos
. Faça login usando SSH como usuário de manutenção no host do Unified Manager.
+
Os prompts do console de manutenção do Unified Manager são exibidos.

. Digite o número da opção de menu rotulada *Configuração do intervalo de sondagem de desempenho* e pressione Enter.
. Caso seja solicitado, digite novamente a senha do usuário de manutenção.
. Digite o número do novo intervalo de pesquisa que você deseja definir e pressione Enter.


Se você alterou o intervalo de coleta do Unified Manager para 10 ou 15 minutos e tem uma conexão ativa com um provedor de dados externo (como o Graphite), você deve alterar o intervalo de transmissão do provedor de dados para que ele seja igual ou maior que o intervalo de coleta do Unified Manager.
