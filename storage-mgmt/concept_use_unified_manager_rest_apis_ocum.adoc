= Use as APIs REST do Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
O Active IQ Unified Manager fornece APIs REST para você visualizar informações sobre o monitoramento e o gerenciamento do seu ambiente de storage. As APIs também permitem o provisionamento e o gerenciamento de objetos de storage com base em políticas.

Você também pode executar APIs do ONTAP em todos os clusters gerenciados pelo ONTAP usando o gateway de API compatível com o Unified Manager.

Para obter informações sobre as REST APIs do Unified Manager, consulte link:../api-automation/concept_get_started_with_um_apis.html["Primeiros passos com as APIs REST do Active IQ Unified Manager"].
