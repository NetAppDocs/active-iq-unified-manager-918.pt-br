= Utilize a caixa de diálogo Cotas no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode usar a opção apropriada na guia User and Group Quotas, na visualização Health: All Storage VMs, para configurar o formato da notificação por e-mail enviada quando ocorre um problema relacionado à cota e para configurar regras que especifiquem endereços de e-mail com base na cota de usuário.
