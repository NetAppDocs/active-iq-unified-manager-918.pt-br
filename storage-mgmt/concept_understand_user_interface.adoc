= Saiba mais sobre a interface de usuário do Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
A interface de usuário do Unified Manager consiste principalmente em um painel que fornece uma visão geral dos objetos que são monitorados. A interface de usuário também permite visualizar todos os objetos do cluster.

Você pode selecionar uma visualização preferida e usar os botões de ação conforme necessário. Sua configuração de tela é salva em um espaço de trabalho, de modo que todas as funcionalidades necessárias estejam disponíveis ao iniciar o Unified Manager. No entanto, ao navegar de uma visualização para outra e, em seguida, retornar, a visualização pode não ser a mesma.
