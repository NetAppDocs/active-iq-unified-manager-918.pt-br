= Edite as configurações do cluster no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode modificar as configurações de um cluster existente, como o nome do host ou endereço IP, nome de usuário, senha e porta, usando a caixa de diálogo Edit Cluster.

.Antes de começar
Você precisa ter a função de Administrador de Aplicativos ou a função de Administrador de Armazenamento.

[NOTE]
====
A partir do Unified Manager 9.7, os clusters podem ser adicionados somente usando HTTPS.

====
.Passos
. No painel de navegação esquerdo, clique em *Gerenciamento de armazenamento* > *Configuração de cluster*.
. Na página *Configuração do Cluster*, selecione o cluster que deseja editar e clique em *Editar*.
. Na caixa de diálogo *Edit Cluster*, modifique os valores conforme necessário. + Se você tiver modificado os detalhes de um cluster adicionado ao Unified Manager, poderá visualizar os detalhes do certificado para comunicação Mutual TLS, com base na versão do ONTAP. Para obter mais informações sobre a versão do ONTAP, consulte link:../storage-mgmt/task_add_clusters.html["Certificados para comunicação TLS mútua"]. + Você pode visualizar os detalhes do certificado clicando em *Certificate Details*. Se o certificado estiver expirado, clique no botão *Regenerate* para incorporar o novo certificado.
. Clique em *Enviar*.
. Na caixa de diálogo Authorize Host, clique em *View Certificate* para visualizar as informações do certificado do cluster.
. Clique em *Yes*.
