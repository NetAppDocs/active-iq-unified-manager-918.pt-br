= Instale, atualize e remova o Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Em sistemas Linux, você pode instalar o software Unified Manager, atualizar para uma versão mais recente do software ou remover o Unified Manager.

O Unified Manager pode ser instalado em servidores Red Hat Enterprise Linux. O servidor Linux no qual você instala o Unified Manager pode estar em execução em uma máquina física ou em uma máquina virtual em execução no VMware ESXi, no Microsoft Hyper-V ou no Citrix XenServer.
