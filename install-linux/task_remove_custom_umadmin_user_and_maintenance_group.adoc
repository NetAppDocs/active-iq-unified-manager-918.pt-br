= Remova o usuário umadmin personalizado e o grupo de manutenção do Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Se você criou um diretório base personalizado para definir seu próprio usuário umadmin e sua conta de manutenção antes de instalar o Unified Manager, remova esses itens depois de desinstalar o Unified Manager.

A desinstalação padrão do Unified Manager não remove um usuário umadmin definido de forma personalizada nem uma conta de manutenção. Você deve excluir esses itens manualmente.

.Passos
. Faça login como o usuário raiz no servidor Red Hat Enterprise Linux.
. Exclua o usuário umadmin:
+
`userdel umadmin`

. Exclua o grupo de manutenção:
+
`groupdel maintenance`
