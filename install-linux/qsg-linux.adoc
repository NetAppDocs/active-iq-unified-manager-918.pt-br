= Comece a usar o Active IQ Unified Manager no Linux
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode baixar o pacote de instalação e instalar o Unified Manager em uma plataforma física ou virtual do Red Hat Enterprise Linux.



[[system-requirements]]
== Requisitos do sistema

* Sistema operacional: Red Hat Enterprise Linux versões 8.x e 9.4, com base na arquitetura x86_64, instalado usando o ambiente base "Server with GUI" da opção *Software Selection* do instalador do sistema operacional
* RAM: 12 GB, CPU: 9572 MHz no total
* Espaço livre em disco: 100 GB de espaço de disco no diretório `/opt/netapp/data`, 50 GB na partição raiz. Para os diretórios `/opt` e `/var/log` montados separadamente, certifique-se de que `/opt` tenha 15 GB, `/var/log` tenha 16 GB e `/tmp` tenha 10 GB de espaço livre.


Para obter requisitos de sistema detalhados e informações sobre como instalar o produto em um local seguro, consulte o link:../install-linux/concept_requirements_for_install_unified_manager.html["Requisitos para instalar o Unified Manager"] e o link:http://mysupport.netapp.com/matrix["Matriz de Interoperabilidade"].



[[install-active-iq-unified-manager]]
== Instale o Active IQ Unified Manager



[[download-the-installer]]
=== Baixe o instalador

. Baixe o `ActiveIQUnifiedManager-<version>.zip` pacote de instalação juntamente com o certificado de assinatura de código (`.pem`) e a assinatura digital (`.sig`).
. No diretório em que você baixou o arquivo de instalação, execute:
+
`# unzip ActiveIQUnifiedManager-<version>.zip`





[[verify-integrity]]
=== Verificar integridade

Execute os seguintes comandos para verificar a integridade do pacote de instalação:

* Execute `openssl x509 -pubkey -noout -in AIQUM-RHEL-CLIENT-INTER-ROOT.pem > <public_key_file_name>` para criar um arquivo com a chave pública do certificado de assinatura de código.
* Execute `openssl dgst -sha256 -verify <public_key_file_name> -signature <signature_file_name> ActiveIQUnifiedManager-<version>.zip` para verificar a assinatura no pacote do instalador.




[[verify-repository-configuration]]
=== Verificar a configuração do repositório

Os procedimentos para configurar um repositório do Red Hat Enterprise Linux são específicos para cada ambiente. Você pode usar o `pre_install_check.sh` script incluído no pacote de instalação para verificar a configuração do seu sistema operacional. Se o seu sistema estiver conectado à internet, você receberá automaticamente as instruções para configurar o repositório do Red Hat Enterprise Linux.

`# sudo ./pre_install_check.sh`



[[install-unified-manager]]
=== Instale o Unified Manager

O Unified Manager utiliza o  `yum` utilitário para instalar o software e qualquer software dependente. Como existem diferentes imagens do Red Hat Enterprise Linux, os pacotes instalados dependem do software presente nas imagens. O  `yum` utilitário determina os pacotes de software dependentes para a instalação. Se você precisar de mais informações sobre os pacotes de software dependentes, consulte link:../install-linux/reference_red_hat_software_and_installation_requirements.html["Requisitos de software e instalação do Linux"].

Para instalar o Unified Manager, execute o seguinte comando, seja como usuário raiz ou usando `sudo`, no diretório em que o arquivo de instalação foi descompactado:

`# yum install netapp-um<version>.x86_64.rpm`

ou

`% sudo yum install netapp-um<version>.x86_64.rpm`

Ao final da instalação, são exibidas as informações para se conectar à interface do usuário da web do Unified Manager. Caso você não consiga se conectar à interface da web, consulte o  `README`arquivo incluído no pacote do software para obter mais informações sobre as restrições da porta 443.
