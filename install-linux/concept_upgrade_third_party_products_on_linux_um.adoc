= Atualize produtos de terceiro após instalar o Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode atualizar produtos de terceiros, como o JRE, mesmo quando o Unified Manager já estiver instalado em sistemas Linux.

As empresas que desenvolvem esses produtos de terceiros relatam vulnerabilidades de segurança regularmente. Você pode atualizar para versões mais recentes deste software quando for mais conveniente para você.
