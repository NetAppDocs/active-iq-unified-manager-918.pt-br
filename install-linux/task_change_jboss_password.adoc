= Alterar a senha do JBoss no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode redefinir a senha específica da instância do JBoss, definida durante a instalação. Opcionalmente, você pode redefinir a senha caso seu site exija esse recurso de segurança para substituir a configuração de instalação do Unified Manager. Essa operação também altera a senha que o JBoss usa para acessar o MySQL.

* Você precisa ter acesso de usuário raiz ao sistema Red Hat Enterprise Linux no qual o Unified Manager está instalado.
* Você deve conseguir acessar o script fornecido pela NetApp `password.sh` no diretório `/opt/netapp/essentials/bin`.


.Passos
. Faça login como usuário raiz no sistema.
. Interrompa os serviços do Unified Manager inserindo os seguintes comandos na ordem apresentada:
+
`systemctl stop ocieau`

+
`systemctl stop ocie`

+
Não interrompa o software MySQL associado.

. Digite o seguinte comando para iniciar o processo de alteração de senha:
+
`/opt/netapp/essentials/bin/password.sh resetJBossPassword`

. Quando solicitado, insira a nova senha do JBoss e, em seguida, insira-a uma segunda vez para confirmação.
+
Observe que a senha deve ter entre 8 e 16 caracteres e deve conter pelo menos um dígito, uma letra maiúscula, uma letra minúscula e pelo menos um destes caracteres especiais:

+
`+!@%^*-_+=[]:<>.?/~+`

. Quando o script for concluído, inicie os serviços do Unified Manager inserindo os seguintes comandos na ordem apresentada:
+
`systemctl start ocie`

+
`systemctl start ocieau`

. Após todos os serviços serem iniciados, você poderá fazer login na interface do usuário do Unified Manager.
