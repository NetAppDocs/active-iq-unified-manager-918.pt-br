= Crie um diretório base de usuário personalizado e uma senha umadmin antes de instalar o Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode criar um diretório base personalizado e definir sua própria senha de usuário umadmin antes de instalar o Unified Manager. Essa tarefa é opcional, mas alguns sites podem precisar da flexibilidade para substituir as configurações padrão de instalação do Unified Manager.

.Antes de começar
* O sistema deve atender aos requisitos descritos em link:concept_virtual_infrastructure_or_hardware_system_requirements.html["Requisitos de hardware do sistema"].
* Você deve conseguir fazer login como o usuário raiz no sistema Red Hat Enterprise Linux.


A instalação padrão do Unified Manager executa as seguintes tarefas:

* Cria o usuário umadmin com `/home/umadmin` como diretório base.
* Atribui a senha padrão "`admin`" ao usuário umadmin.


Como alguns ambientes de instalação restringem o acesso a `/home`, a instalação falha. Você deve criar o diretório base em um local diferente. Além disso, alguns sites podem ter regras sobre a complexidade da senha ou exigir que as senhas sejam definidas por administradores locais em vez de serem definidas pelo programa de instalação.

Se o seu ambiente de instalação exigir que você substitua essas configurações padrão da instalação, siga estas etapas para criar um diretório base personalizado e definir a senha do usuário umadmin.

Quando essas informações são definidas antes da instalação, o script de instalação detecta essas configurações e usa os valores definidos em vez de usar as configurações padrão da instalação.

Além disso, a instalação padrão do Unified Manager inclui o usuário umadmin nos arquivos sudoers (`ocum_sudoers` e `ocie_sudoers`) no `/etc/sudoers.d/` diretório. Se você remover esse conteúdo do seu ambiente devido a políticas de segurança ou por causa de alguma ferramenta de monitoramento de segurança, deverá adicioná-lo novamente. Você precisa preservar a configuração do sudoers, pois algumas operações do Unified Manager exigem esses privilégios de sudo.

As políticas de segurança do seu ambiente não devem restringir os privilégios sudo para o usuário de manutenção do Unified Manager. Algumas operações do Unified Manager podem falhar se os privilégios forem restritos. Verifique se você consegue executar o seguinte comando sudo ao fazer login como o usuário umadmin após a instalação.

`sudo systemctl  status ocie`

Este comando deve retornar o status apropriado do serviço ocie sem erros.

.Passos
. Faça login no servidor como usuário raiz.
. Crie a conta do grupo umadmin chamada "`maintenance`":
+
`groupadd maintenance`

. Crie a conta de usuário "`umadmin`" no grupo de manutenção em um diretório base de sua escolha:
+
`adduser --home <home_directory\> -g maintenance umadmin`

. Defina a senha do umadmin:
+
`passwd umadmin`

+
O sistema solicita que você insira uma nova string de senha para o usuário umadmin.



Após instalar o Unified Manager, você deve especificar o shell de login do usuário umadmin.
