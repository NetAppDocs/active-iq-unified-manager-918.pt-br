= Crie um relatório para visualizar as VMs de armazenamento que estão atingindo o limite máximo de volumes no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode criar um relatório para encontrar SVMs que estão atingindo o limite máximo de volume.

.Antes de começar
* Você precisa ter a função de Application Administrator ou Storage Administrator.


Siga as etapas a seguir para criar uma visualização personalizada que mostre as VMs de storage que estão atingindo o limite máximo de volume e, em seguida, agende a geração de um relatório para essa visualização.

.Passos
. No painel de navegação esquerdo, clique em *Armazenamento* > *VMs de armazenamento*.
. Selecione *Mostrar/Ocultar* para remover as colunas que você não quer no relatório.
. Arraste as colunas "`Volume Count`" e "`Maximum Allowed Volumes`" para perto da coluna "`Storage VM`".
. Clique na parte superior da coluna "`Volumes Máximos Permitidos`" para classificar os resultados pelo maior número de volumes.
. Salve a visualização com um nome específico que reflita o que a visualização está mostrando, por exemplo "`SVMs atingindo volumes máximos`" e clique na marca de seleção (image:../media/blue_check.gif[""]).
. Clique no botão *Relatórios Agendados* na página de inventário.
. Clique em *Add Schedule* para adicionar uma nova linha à página *Report Schedules*, para que você possa definir as características do agendamento para o novo relatório.
. Insira um nome para o cronograma do relatório e preencha os outros campos do relatório, depois clique na marca de seleção (image:../media/blue_check.gif[""]) no final da linha.
+
O relatório é enviado imediatamente como teste. Depois disso, o relatório é gerado e enviado por e-mail aos destinatários listados na frequência especificada.



Com base nos resultados apresentados no relatório, você pode querer equilibrar os volumes atribuídos às VMs de storage ou, se possível, usar o ONTAP System Manager para alterar o número máximo de volumes permitidos.
