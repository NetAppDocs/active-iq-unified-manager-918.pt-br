= Crie um relatório para visualizar as VMs de armazenamento interrompidas no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode criar um relatório para exibir uma lista de todas as SVMs paradas.

.Antes de começar
* Você precisa ter a função de Application Administrator ou Storage Administrator.


Siga os passos abaixo para criar uma visualização personalizada que mostre as VMs de storage paradas e, em seguida, agende a geração de um relatório para essa visualização.

.Passos
. No painel de navegação esquerdo, clique em *Armazenamento* > *VMs de armazenamento*.
. No menu Exibir, selecione *Saúde* > *Todas as VMs de storage*.
. Selecione *Mostrar/Ocultar* para remover quaisquer colunas que você não queira no relatório.
. Arraste a coluna "`State`" para perto da coluna "`Storage VM`".
. Clique no ícone de filtro, adicione o seguinte filtro e, em seguida, clique em *Apply Filter*:
+
** O estado está parado


. Salve a visualização com um nome específico que reflita o que a visualização está mostrando, por exemplo "`SVMs parados`" e clique na marca de seleção (image:../media/blue_check.gif[""]).
. Clique no botão *Relatórios Agendados* na página de inventário.
. Clique em *Add Schedule* para adicionar uma nova linha à página *Report Schedules*, para que você possa definir as características do agendamento para o novo relatório.
. Insira um nome para o cronograma do relatório e preencha os outros campos do relatório, depois clique na marca de seleção (image:../media/blue_check.gif[""]) no final da linha.
+
O relatório é enviado imediatamente como teste. Depois disso, o relatório é gerado e enviado por e-mail aos destinatários listados na frequência especificada.



Com base nos resultados apresentados no relatório, talvez você queira investigar por que a SVM está parada para verificar se deve reiniciar as SVMs paradas.
