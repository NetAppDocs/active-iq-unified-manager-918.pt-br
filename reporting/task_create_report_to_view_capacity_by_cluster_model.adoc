= Crie um relatório para visualizar a capacidade por modelo de cluster no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode criar um relatório para analisar a capacidade de storage e a utilização de clusters com base no modelo do sistema de storage.

.Antes de começar
* Você precisa ter a função de Application Administrator ou Storage Administrator.


Siga os passos abaixo para criar uma visualização personalizada que mostre a capacidade por modelo de cluster e, em seguida, agende a geração de um relatório para essa visualização.

.Passos
. No painel de navegação esquerdo, clique em *Armazenamento* > *Clusters*.
. No menu Exibir, selecione *Capacidade* > *Todos os Clusters*.
. Selecione *Show/Hide* para remover quaisquer colunas, como "`Cluster FQDN`" e "`OS Version`", que você não deseja no relatório.
. Arraste as colunas "`Total Raw Capacity`", "`Model/Family`" e as três colunas de agregado para perto da coluna "`Cluster`".
. Clique na parte superior da coluna "`Model/Family`" para classificar os resultados por tipo de cluster.
. Salve a visualização com um nome específico que reflita o que ela está exibindo, por exemplo, "`Capacidade por Modelo de Cluster`".
. Clique no botão *Relatórios Agendados* na página de inventário.
. Clique em *Add Schedule* para adicionar uma nova linha à página *Report Schedules*, para que você possa definir as características do agendamento para o novo relatório.
. Insira um nome para o cronograma do relatório e preencha os outros campos do relatório, depois clique na marca de seleção (image:../media/blue_check.gif[""]) no final da linha.
+
O relatório é enviado imediatamente como teste. Depois disso, o relatório é gerado e enviado por e-mail aos destinatários listados na frequência especificada.



Com base nos resultados apresentados no relatório, você pode querer adicionar mais capacidade a determinados clusters ou atualizar modelos de cluster mais antigos.
