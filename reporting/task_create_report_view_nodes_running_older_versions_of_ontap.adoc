= Crie um relatório para visualizar os nós que executam versões antigas do ONTAP no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode criar um relatório para exibir a versão do software ONTAP instalada em todos os nós do cluster, permitindo identificar quais nós devem ser atualizados.

.Antes de começar
* Você precisa ter a função de Application Administrator ou Storage Administrator.


Siga os passos abaixo para criar uma visualização personalizada que exiba os nós que executam versões mais antigas do ONTAP e, em seguida, agende a geração de um relatório para essa visualização.

.Passos
. No painel de navegação esquerdo, clique em *Armazenamento* > *Nós*.
. Selecione *Mostrar/Ocultar* para remover quaisquer colunas que você não queira no relatório.
. Arraste a coluna "`OS Version`" para perto da coluna "`Node`".
. Clique na parte superior da coluna "`OS Version`" para classificar os resultados pela versão mais antiga do ONTAP.
. Salve a visualização com um nome específico que reflita o que ela está mostrando, por exemplo, "`Nós por versão do ONTAP`".
. Clique no botão *Relatórios Agendados* na página de inventário.
. Clique em *Adicionar Cronograma* para adicionar uma nova linha à página Cronogramas de Relatório, para que você possa definir as características do agendamento do novo relatório.
. Insira um nome para o cronograma do relatório e preencha os outros campos do relatório, depois clique na marca de seleção (image:../media/blue_check.gif[""]) no final da linha.
+
O relatório é enviado imediatamente como teste. Depois disso, o relatório é gerado e enviado por e-mail aos destinatários listados na frequência especificada.



Com base nos resultados apresentados no relatório, talvez seja interessante atualizar os nós que executam versões mais antigas do ONTAP.
