= Crie um relatório para visualizar volumes usando a política de exportação padrão no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode criar um relatório para encontrar volumes que estejam usando a política de exportação padrão.

.Antes de começar
* Você precisa ter a função de Application Administrator ou Storage Administrator.


Siga os passos abaixo para criar uma visualização personalizada para volumes que utilizam a política de exportação padrão e, em seguida, agende a geração de um relatório para essa visualização.

.Passos
. No painel de navegação esquerdo, clique em *Armazenamento* > *Compartilhamentos NFS*.
. Selecione *Mostrar/Ocultar* para remover quaisquer colunas que você não queira no relatório.
. Arraste a coluna "`Export Policy`" para perto da coluna "`Volume`".
. Clique no ícone de filtro, adicione o seguinte filtro e, em seguida, clique em *Apply Filter*:
+
** A política de exportação contém o padrão


. Salve a visualização com um nome específico que reflita o que a visualização está mostrando, por exemplo "`Volumes com uma política de exportação padrão`" e clique na marca de seleção (image:../media/blue_check.gif[""]).
. Clique no botão *Relatórios Agendados* na página de inventário.
. Clique em *Adicionar agendamento* para adicionar uma nova linha à página Agendamentos de relatório, para que você possa definir as características do agendamento do novo relatório.
. Insira um nome para o cronograma do relatório e preencha os outros campos do relatório, depois clique na marca de seleção (image:../media/blue_check.gif[""]) no final da linha.
+
O relatório é enviado imediatamente como teste. Depois disso, o relatório é gerado e enviado por e-mail aos destinatários listados na frequência especificada.



Com base nos resultados mostrados no relatório, você talvez queira configurar uma política de exportação personalizada.
