= Defina objetos correlacionados para gráficos de comparação no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
No painel Gráfico de contadores, você pode definir uma lista de objetos correlacionados para comparação de dados e desempenho. Por exemplo, se sua máquina virtual de armazenamento (SVM) estiver apresentando um problema de desempenho, você pode comparar todos os volumes da SVM para identificar qual volume pode estar causando o problema.

Você pode adicionar qualquer objeto da grade de objetos correlacionados aos painéis de gráfico de comparação e de contador. Isso permite que você visualize e compare dados de vários objetos e com o objeto raiz. Você pode adicionar e remover objetos da grade de objetos correlacionados; no entanto, o objeto raiz no painel de comparação não pode ser removido.

[NOTE]
====
Adicionar muitos objetos ao painel Comparar pode afetar negativamente o desempenho. Para manter o desempenho, selecione um número limitado de gráficos para comparação de dados.

====
.Passos
. Na grade de objetos, localize o objeto que você deseja adicionar e clique no botão *Adicionar*.
+
O botão *Adicionar* fica cinza, e o objeto é adicionado à lista de objetos adicionais no painel Comparando. Os dados do objeto são adicionados aos gráficos nos painéis Gráficos de Contador. A cor do ícone de olho do objeto (image:../media/eye_icon.gif[""]) corresponde à cor da linha de tendência dos dados do objeto nos gráficos.

. *Opcional:* Ocultar ou exibir dados para objetos selecionados:
+
|===
| Para fazer isso... | Faça o seguinte... 


 a| 
Ocultar um objeto selecionado
 a| 
Clique no ícone de olho (image:../media/eye_icon.gif[""]) do objeto selecionado no painel Comparing. Os dados do objeto ficam ocultos, e o ícone de olho desse objeto fica cinza.



 a| 
Mostrar um objeto oculto
 a| 
Clique no ícone de olho cinza do objeto selecionado no painel Comparing.

O ícone do olho retorna à sua cor original, e os dados do objeto são adicionados novamente aos gráficos no painel Gráficos de Contador.

|===
. *Opcional:* Remova os objetos selecionados do painel *Comparing*:
+
|===
| Para fazer isso... | Faça o seguinte... 


 a| 
Remover um objeto selecionado
 a| 
No painel Comparando, passe o cursor sobre o nome do objeto selecionado para exibir o botão Remover objeto (*X*) e clique nele. O objeto é removido do painel Comparando, e seus dados são apagados dos gráficos de contadores.



 a| 
Remover todos os objetos selecionados
 a| 
Clique no botão "Remover todos os objetos" (*X*) na parte superior do painel de comparação. Todos os objetos selecionados e seus dados são removidos, restando apenas o objeto raiz.

|===
