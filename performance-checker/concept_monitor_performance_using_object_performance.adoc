= Monitore o desempenho de objetos usando as páginas de Inventário de Desempenho no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
As páginas de desempenho do inventário de objetos exibem informações de desempenho, eventos de desempenho e integridade dos objetos para todos os objetos em uma categoria de tipo de objeto. Isso fornece a você uma visão geral rápida do status de desempenho de cada objeto em um cluster, por exemplo, para todos os nós ou todos os volumes.

As páginas de desempenho do inventário de objetos fornecem uma visão geral de alto nível do status dos objetos, permitindo que você avalie o desempenho geral de todos os objetos e compare os dados de desempenho dos objetos. Você pode refinar o conteúdo das páginas de inventário de objetos pesquisando, classificando e filtrando. Isso é útil para monitorar e gerenciar o desempenho dos objetos, pois permite que você localize rapidamente objetos com problemas de desempenho e inicie o processo de solução de problemas.

image::../media/perf_node_inventory.gif[Uma captura de tela da interface do usuário que mostra os detalhes do objeto na página de inventário Performance/All Nodes.]

Por padrão, os objetos nas páginas de inventário de desempenho são classificados com base na criticidade do desempenho do objeto. Os objetos com novos eventos críticos de desempenho aparecem primeiro, e os objetos com eventos de aviso aparecem em segundo lugar. Isso fornece uma indicação visual imediata dos problemas que precisam ser resolvidos. Todos os dados de desempenho se baseiam em uma média de 72 horas.

Você pode navegar facilmente da página de desempenho do inventário de objetos para uma página de detalhes do objeto clicando no nome do objeto na coluna de nome do objeto. Por exemplo, na página de inventário Performance/All Nodes, você clicaria em um objeto de nó na coluna *Nodes*. A página de detalhes do objeto fornece informações detalhadas sobre o objeto selecionado, incluindo uma comparação lado a lado dos eventos ativos.
