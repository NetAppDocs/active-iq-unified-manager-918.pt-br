= Analise as recomendações do Active IQ Unified Manager para o armazenamento em camadas de dados na nuvem
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
A visualização Performance: All Volumes exibe informações relacionadas ao tamanho dos dados de usuário armazenados no volume que está inativo (frio). Em alguns casos, o Unified Manager identifica determinados volumes que se beneficiariam com a disposição em camadas dos dados inativos para a camada de nuvem (provedor de nuvem ou o StorageGRID) de um agregado habilitado para FabricPool.

[NOTE]
====
O FabricPool foi introduzido no ONTAP 9.2, portanto, se você estiver usando uma versão do software ONTAP anterior à 9.2, a recomendação do Unified Manager para fazer o armazenamento em camadas dos dados exige que você atualize o software ONTAP. Além disso, a `*auto*` política de armazenamento em camadas foi introduzida no ONTAP 9.4, e a `*all*` política de armazenamento em camadas foi introduzida no ONTAP 9.6, portanto, se a recomendação for usar a política de armazenamento em camadas automática, você deverá atualizar para o ONTAP 9.4 ou superior.

====
Os três campos a seguir na visualização Performance: All Volumes fornecem informações sobre se você pode melhorar a utilização de disco do seu sistema de storage e economizar espaço na camada de desempenho movendo dados inativos para a camada de nuvem.

* *Política de disposição em camadas*
+
A política de hierarquização determina se os dados no volume permanecem na camada de desempenho ou se parte dos dados é movida da camada de desempenho para a camada de nuvem.

+
O valor neste campo indica a política de hierarquização definida no volume, mesmo que o volume não esteja atualmente em um agregado FabricPool. A política de hierarquização só entra em vigor quando o volume está em um agregado FabricPool.

* *Dados frios*
+
Os dados frios exibem o tamanho dos dados de usuário armazenados no volume que está inativo (frio).

+
Um valor é exibido aqui somente ao usar o software ONTAP 9.4 ou superior, pois isso requer que o agregado no qual o volume está implantado tenha o `*inactive data reporting parameter*` definido como `*enabled*`, e que o limite mínimo do número de dias de resfriamento tenha sido atingido (para volumes que usam a política de tiering `*snapshot-only*` ou `*auto*`). Caso contrário, o valor aparece como "`N/A`".

* *Recomendação de nuvem*
+
Após a coleta de informações suficientes sobre a atividade de dados no volume, o Unified Manager pode determinar que nenhuma ação é necessária ou que você pode economizar espaço na camada de desempenho movendo os dados inativos para a camada de nuvem.



[NOTE]
====
O campo Dados Frios é atualizado a cada 15 minutos, enquanto o campo Recomendação na Nuvem é atualizado a cada 7 dias quando a análise de dados frios é realizada no volume. Portanto, a quantidade exata de dados frios pode diferir entre os campos. O campo Recomendação na Nuvem exibe a data em que a análise foi executada.

====
Quando o Inactive Data Reporting está ativado, o campo Cold Data exibe a quantidade exata de dados inativos. Sem o recurso de relatório de dados inativos, o Unified Manager usa estatísticas de desempenho para determinar se os dados estão inativos em um volume. A quantidade de dados inativos não é exibida no campo Cold Data nesse caso, mas é exibida quando você passa o cursor sobre a palavra *Tier* para visualizar a recomendação de nuvem.

As recomendações de nuvem que você verá são:

* *Aprendendo*. Não foram coletados dados suficientes para fazer uma recomendação.
* *Nível*. A análise determinou que o volume contém dados inativos (frios) e que você deve configurar o volume para mover esses dados para a camada de nuvem. Em alguns casos, isso pode exigir que você mova primeiro o volume para um agregado habilitado para FabricPool. Em outros casos, quando o volume já está em um agregado FabricPool, basta alterar a política de categorização em camadas.
* *Nenhuma ação*. Ou o volume tem poucos dados inativos, o volume já está configurado com a política de armazenamento em camadas "`auto`" em um agregado do FabricPool, ou o volume é um volume de proteção de dados. Esse valor também é exibido quando o volume está offline ou quando está sendo usado em uma configuração do MetroCluster.


Para mover um volume, alterar a política de hierarquização de volume ou as configurações de relatório de dados inativos do agregado, use o ONTAP System Manager, os comandos da ONTAP CLI ou uma combinação dessas ferramentas.

Se você estiver conectado ao Unified Manager com a função Application Administrator ou Storage Administrator, o link *Configure Volume* estará disponível na recomendação na nuvem ao posicionar o cursor sobre a palavra *Tier*. Clique neste botão para abrir a página Volumes no System Manager e fazer a alteração recomendada.
