= Identifique cargas de trabalho excessivas em eventos de desempenho dinâmicos no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
No Unified Manager, você pode identificar quais cargas de trabalho têm o maior desvio de uso em um componente do cluster em contenção. Identificar essas cargas de trabalho ajuda você a entender por que determinados volumes no cluster têm tempos de resposta lentos (latência).

.Antes de começar
* Você precisa ter a função de Operador, Administrador de Aplicativos ou administrador de storage.
* Deve haver eventos de desempenho dinâmico novos, reconhecidos ou obsoletos.


A página de detalhes do evento exibe uma lista das cargas de trabalho definidas pelo usuário e pelo sistema, classificadas pelo maior uso do componente ou pelo maior impacto causado pelo evento. Os valores são baseados nos picos que o Unified Manager identificou quando detectou e analisou o evento pela última vez.

.Passos
. Exiba a página de detalhes do evento para visualizar informações sobre o evento.
. Nos gráficos de latência da carga de trabalho e atividade da carga de trabalho, selecione *Bully Workloads*.
. Passe o cursor sobre os gráficos para visualizar as principais cargas de trabalho agressoras definidas pelo usuário que estão afetando o componente.
