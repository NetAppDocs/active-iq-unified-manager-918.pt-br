= Atribua políticas de limite de desempenho a objetos de storage no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você atribui uma política de limite de desempenho definida pelo usuário a um objeto de armazenamento para que o Unified Manager registre um evento se o valor do contador de desempenho exceder a configuração da política.

.Antes de começar
Você precisa ter a função de Application Administrator.

A política ou as políticas de limite de desempenho que você deseja aplicar ao objeto devem existir.

Você pode aplicar apenas uma política de desempenho por vez a um objeto ou a um grupo de objetos.

Você pode atribuir no máximo três políticas de limite a cada objeto de armazenamento. Ao atribuir políticas a vários objetos, se algum dos objetos já tiver o número máximo de políticas atribuídas, o Unified Manager executará as seguintes ações:

* Aplica a política a todos os objetos selecionados que ainda não atingiram seu valor máximo
* Ignora os objetos que já atingiram o número máximo de políticas
* Exibe uma mensagem informando que a política não foi atribuída a todos os objetos


.Passos
. Na página de inventário de desempenho de qualquer objeto de armazenamento, selecione o objeto ou os objetos aos quais você deseja atribuir uma política de limite:
+
|===
| Para atribuir limites a... | Clique... 


 a| 
Um único objeto
 a| 
A caixa de seleção à esquerda desse objeto.



 a| 
Vários objetos
 a| 
A caixa de seleção à esquerda de cada objeto.



 a| 
Todos os objetos na página
 a| 
Na caixa suspensa image:../media/select_dropdown_65_png.gif["Selecione o ícone de lista suspensa"], escolha *Selecionar todos os objetos desta página*.



 a| 
Todos os objetos do mesmo tipo
 a| 
Na image:../media/select_dropdown_65_png.gif["Selecione o ícone de lista suspensa"]caixa suspensa, escolha *Selecionar todos os objetos*.

|===
+
Você pode usar a funcionalidade de classificação e filtragem para refinar a lista de objetos na página de inventário, facilitando a aplicação de políticas de limite a vários objetos.

. Faça sua seleção e, em seguida, clique em *Atribuir Política de Limite de Desempenho*.
+
A página "Atribuir Política de Limite de Desempenho" é exibida e mostra uma lista das políticas de limite existentes para esse tipo específico de objeto de armazenamento.

. Clique em cada política para exibir os detalhes das configurações de limite de desempenho e verificar se você selecionou a política de limite correta.
. Após selecionar a política de limite apropriada, clique em *Atribuir Política*.
+
Uma mensagem de sucesso na parte superior da página confirma que a política de limite foi atribuída ao objeto ou aos objetos e fornece um link para a página de alertas para que você possa configurar as configurações de alerta para este objeto e esta política.



Se você quiser que os alertas sejam enviados por e-mail ou como um trap SNMP para notificar você de que um determinado evento de desempenho foi gerado, você deve configurar as definições de alerta na página Alert Setup.
