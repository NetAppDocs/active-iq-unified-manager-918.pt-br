= Entenda os eventos de QoS adaptável com um tamanho de bloco definido no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Os grupos de políticas de QoS adaptáveis dimensionam automaticamente um limite máximo ou mínimo de taxa de transferência com base no tamanho do volume, mantendo a proporção de IOPS para TBs à medida que o tamanho do volume muda. A partir do ONTAP 9.5, você pode especificar o tamanho do bloco na política de QoS para aplicar efetivamente um limite de MB/s simultaneamente.

Atribuir um limite de IOPS em uma política de QoS adaptável limita apenas o número de operações que ocorrem em cada carga de trabalho. Dependendo do tamanho do bloco definido no cliente que gera as cargas de trabalho, algumas IOPS incluem muito mais dados e, portanto, impõem uma carga muito maior aos nós que processam as operações.

O valor em MB/s para uma carga de trabalho é gerado usando a seguinte fórmula:

[listing]
----
MB/s = (IOPS * Block Size) / 1000
----
Se uma carga de trabalho tiver uma média de 3.000 IOPS e o tamanho do bloco no cliente estiver definido como 32 KB, a taxa de transferência efetiva (MB/s) para essa carga de trabalho será de 96. Se essa mesma carga de trabalho tiver uma média de 3.000 IOPS e o tamanho do bloco no cliente estiver definido como 48 KB, a taxa de transferência efetiva (MB/s) para essa carga de trabalho será de 144. É possível observar que o nó processa 50% mais dados quando o tamanho do bloco é maior.

Vamos analisar a seguinte política de QoS adaptável, que tem um tamanho de bloco definido, e como os eventos são acionados com base no tamanho de bloco configurado no cliente.

Crie uma política e defina o limite de taxa de transferência para 2.500 IOPS/TB com um tamanho de bloco de 32 KB. Isso define efetivamente o limite de MB/s como 80 MB/s ((2.500 IOPS * 32 KB) / 1.000) para um volume com 1 TB de capacidade usada. Observe que o Unified Manager gera um evento de aviso quando o valor da taxa de transferência é 10% menor que o limite definido. Os eventos são gerados nas seguintes situações:

|===
| Capacidade utilizada 2+| O evento é gerado quando a taxa de transferência excede esse número de ... 


|  | IOPS | MB/s

 a|

 a|

|===
Se o volume estiver usando 2 TB do espaço disponível, e o IOPS for 4.000, e o tamanho do bloco de QoS estiver definido como 32 KB no cliente, então a taxa de transferência em MB/ps será de 128 MB/s ((4.000 IOPS * 32 KB) / 1000). Nenhum evento é gerado neste cenário porque tanto 4.000 IOPS quanto 128 MB/s estão abaixo do limite para um volume que está usando 2 TB de espaço.

Se o volume estiver usando 2 TB do espaço disponível, e o IOPS for 4.000, e o tamanho do bloco de QoS estiver definido como 64 KB no cliente, então a taxa de transferência em MB/s será de 256 MB/s ((4.000 IOPS * 64 KB) / 1000). Nesse caso, os 4.000 IOPS não geram um evento, mas o valor de 256 MB/s está acima do limite de 144 MB/s e gera um evento.

Por esse motivo, quando um evento é acionado com base em uma violação de MB/s para uma política de QoS adaptável que inclui o tamanho do bloco, um gráfico de MB/s é exibido na seção System Diagnosis da página Event details. Se o evento for acionado com base em uma violação de IOPS para a política de QoS adaptável, um gráfico de IOPS é exibido na seção System Diagnosis. Se ocorrer uma violação tanto de IOPS quanto de MB/s, você receberá dois eventos.

Para obter mais informações sobre como ajustar as configurações de QoS, consulte https://docs.netapp.com/us-en/ontap/performance-admin/index.html["Visão geral do gerenciamento de desempenho"].
