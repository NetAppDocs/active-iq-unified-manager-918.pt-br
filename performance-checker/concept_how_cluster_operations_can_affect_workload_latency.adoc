= Avalie como as operações de cluster podem afetar a latência no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
As operações (IOPS) representam a atividade de todas as cargas de trabalho definidas pelo usuário e pelo sistema em um cluster. As estatísticas de IOPS ajudam você a determinar se os processos do cluster, como a criação de backups ou a execução de deduplicação, estão afetando a latência da carga de trabalho (tempo de resposta) ou podem ter causado ou contribuído para um evento de desempenho.

Ao analisar eventos de desempenho, você pode usar as estatísticas de IOPS para determinar se um evento de desempenho foi causado por um problema no cluster. Você pode identificar as atividades de carga de trabalho específicas que podem ter sido as principais responsáveis pelo evento de desempenho. As IOPS são medidas em operações por segundo (ops/sec).

image::../media/opm_ops_chart_png.png[Gráfico de IOPS do Unified Manager]

Este exemplo mostra o gráfico de IOPS. As estatísticas reais de operações são representadas por uma linha azul, e a previsão de IOPS das estatísticas de operações é representada pela linha verde.

[NOTE]
====
Em alguns casos em que um cluster está sobrecarregado, o Unified Manager pode exibir a mensagem `Data collection is taking too long on Cluster _cluster_name_`. Isso significa que estatísticas suficientes não foram coletadas para o Unified Manager analisar. Você precisa reduzir os recursos que o cluster está usando para que estatísticas possam ser coletadas.
