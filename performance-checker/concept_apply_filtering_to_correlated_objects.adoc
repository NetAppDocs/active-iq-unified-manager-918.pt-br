= Filtre objetos correlacionados na grade do Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
A filtragem permite exibir um subconjunto menor e mais bem definido de objetos na grade. Por exemplo, se você tiver 25 volumes na grade, a filtragem permite visualizar apenas os volumes com taxa de transferência inferior a 90 MBps ou latência superior a 1 ms/op.
