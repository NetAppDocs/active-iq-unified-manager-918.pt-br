= Analise a página inicial do Cluster de Desempenho no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
A página inicial do cluster de desempenho exibe o status de desempenho de alto nível de um cluster selecionado. A página permite que você acesse detalhes completos de cada contador de desempenho dos objetos de armazenamento no cluster selecionado.

A página inicial do cluster de desempenho inclui quatro abas que separam os detalhes do cluster em quatro áreas de informação:

* Página de resumo
+
** Painel de eventos do cluster
** Gráficos de desempenho em MB/s e IOPS
** Painel de Objetos Gerenciados


* Página dos Melhores Desempenhos
* Página do explorador
* Página de informações
