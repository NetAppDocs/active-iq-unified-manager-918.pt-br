= Analise eventos a partir de limites de desempenho dinâmicos no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Os eventos gerados a partir de limites dinâmicos indicam que o tempo de resposta (latência) real de uma carga de trabalho está muito alto ou muito baixo em comparação com a faixa de tempo de resposta esperada. Você usa a página Detalhes do evento para analisar o evento de desempenho e tomar medidas corretivas, se necessário, para restaurar o desempenho ao normal.

[NOTE]
====
Os limites de desempenho dinâmicos não estão habilitados nos sistemas Cloud Volumes ONTAP, ONTAP Edge ou ONTAP Select.
