= Avalie como as alterações de configuração afetam o desempenho da carga de trabalho no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Alterações na configuração do cluster, como um disco com falha, failover de HA ou um volume movido, podem afetar negativamente o desempenho do volume e causar aumento da latência.

No Unified Manager, você pode revisar a página Workload Analysis para ver quando ocorreu uma alteração recente na configuração e compará-la com as operações e a latência (tempo de resposta) para ver se houve alguma mudança na atividade da carga de trabalho do volume selecionado.

As páginas de desempenho do Unified Manager só conseguem detectar um número limitado de eventos de alteração. As páginas de integridade fornecem alertas para outros eventos causados por alterações de configuração. Você pode pesquisar o volume no Unified Manager para ver o histórico de eventos.
