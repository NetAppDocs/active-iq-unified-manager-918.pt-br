= Determine as ações corretivas na página Planejamento de Failover de Desempenho/Nó no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Com base nas informações exibidas na página Performance/Node Failover Planning, você pode tomar medidas para garantir que um failover não faça com que o desempenho de um par de HA caia abaixo de um nível aceitável.

Por exemplo, para reduzir o impacto estimado no desempenho em caso de failover, você pode mover alguns volumes ou LUNs de um nó no par de HA para outros nós no cluster. Isso garante que o nó primário possa continuar a fornecer um desempenho aceitável após um failover.
