= Entenda como a adição de discos afeta a realocação de dados no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode adicionar discos a um agregado para aumentar a capacidade de storage e o desempenho desse agregado. Após adicionar os discos, você verá uma melhoria no desempenho de leitura somente depois de realocar os dados entre os discos que você adicionou.

Você pode usar estas instruções quando o Unified Manager tiver recebido eventos de agregado acionados por limites dinâmicos ou por limites de desempenho definidos pelo sistema:

* Quando você recebe um evento de limite dinâmico, na página de detalhes do evento, o ícone do componente do cluster que representa o agregado em disputa fica destacado em vermelho.
+
Abaixo do ícone, entre parênteses, está o nome do agregado, que identifica o agregado ao qual você pode adicionar discos.

* Quando você recebe um evento de limite definido pelo sistema, na página Detalhes do evento, o texto de descrição do evento lista o nome do agregado que está apresentando o problema.
+
Você pode adicionar discos e realocar dados neste agregado.



Os discos que você adicionar ao agregado já devem existir no cluster. Se o cluster não tiver discos adicionais disponíveis, talvez seja necessário entrar em contato com seu administrador ou adquirir mais discos. Você pode usar o ONTAP System Manager ou os comandos do ONTAP para adicionar discos a um agregado.

[NOTE]
====
Você deve realocar dados somente ao usar agregados de HDD e Flash Pool. Não realoque dados em agregados SSD ou FabricPool.
