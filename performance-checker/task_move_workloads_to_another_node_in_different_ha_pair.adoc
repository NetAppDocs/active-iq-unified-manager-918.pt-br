= Mova as cargas de trabalho para outro nó em um par de HA no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode usar o Unified Manager para ajudar a identificar um agregado em um nó de um par de HA diferente que esteja menos ocupado do que o par de HA onde suas cargas de trabalho estão sendo executadas atualmente. Em seguida, você pode mover volumes selecionados para agregados no novo par de HA. Mover cargas de trabalho de alto desempenho para um agregado em um nó menos ocupado permite que as cargas de trabalho em ambos os nós tenham um desempenho mais eficiente.

.Antes de começar
* Você precisa ter a função de Operador, Administrador de Aplicativos ou administrador de storage.
* Seu cluster deve consistir em no mínimo dois pares de HA; você não pode usar este processo de correção se tiver apenas um par de HA em seu cluster.
* Você deve ter anotado os nomes dos dois nós do par de HA que estão apresentando o problema de desempenho.
* Você deve ter registrado a data e a hora em que os nós receberam o evento de desempenho.
* O Unified Manager deve ter coletado e analisado dados de desempenho referentes a um mês ou mais.


Estas etapas ajudam você a identificar os seguintes recursos para que possa mover cargas de trabalho de alto desempenho para um nó menos utilizado em um par de HA diferente:

* Os nós em um par de HA diferente no mesmo cluster que são menos utilizados
* Os agregados nos novos nós que são menos utilizados
* Os volumes de melhor desempenho nos nós atuais


.Passos
. Identifique os nós que fazem parte de um par de HA diferente no mesmo cluster:
+
.. No painel de navegação à esquerda, clique em *Armazenamento* > *Clusters* e selecione *Desempenho* > *Todos os Clusters* no menu Exibir.
+
A visualização Desempenho: todos os clusters é exibida.

.. Clique no número no campo *Node Count* do cluster atual.
+
A visualização "Desempenho: todos os Nós" é exibida.

.. Anote os nomes dos nós que estão em pares de HA diferentes do par de HA que está apresentando o problema de desempenho.


. Identifique um nó no novo par de HA que seja o menos utilizado:
+
.. Clique na coluna *Utilização* para classificar os nós por ordem de menor utilização.
+
Você também pode identificar os nós que têm a maior *Capacidade Livre*. Isso fornece uma lista de nós potenciais para os quais você pode querer mover cargas de trabalho.

.. Anote o nome do nó para o qual você deseja mover as cargas de trabalho.


. Identifique um agregado no novo nó que seja o menos utilizado:
+
.. No painel de navegação à esquerda, clique em *Armazenamento* > *Agregados* e selecione *Desempenho* > *Todos os Agregados* no menu *Exibir*.
+
A visualização Performance: All Aggregates é exibida.

.. Clique em *Filtragem*, selecione *Nó* no menu suspenso à esquerda, digite o nome do nó no campo de texto e clique em *Aplicar filtro*.
+
A visualização Performance: All Aggregates é exibida novamente com a lista de agregados disponíveis neste nó.

.. Clique na coluna *Utilização* para classificar os agregados pelos menos utilizados.
+
Você também pode identificar os agregados que possuem a maior *Capacidade Livre*. Isso fornece uma lista de agregados potenciais para os quais você pode querer mover cargas de trabalho.

.. Anote o nome do agregado para o qual você deseja mover as cargas de trabalho.


. Identifique as cargas de trabalho de alto desempenho nos nós que receberam o evento:
+
.. Volte para a página de detalhes do *Event* do evento.
.. No campo *Volumes Afetados*, clique no link correspondente ao número de volumes do primeiro nó.
+
A visualização Desempenho: todos os volumes exibe uma lista filtrada dos volumes naquele nó.

.. Clique na coluna *Capacidade Total* para classificar os volumes pelo maior espaço alocado.
+
Isso fornece uma lista de volumes em potencial que você pode querer mover.

.. Anote os nomes dos volumes que você deseja mover e os nomes dos agregados atuais nos quais eles se encontram.
.. Execute os passos 4c e 4d para o segundo nó que fez parte deste evento para identificar possíveis volumes que você também deseja mover desse nó.


. Transfira os volumes para os agregados que você identificou com baixa utilização no novo nó.
+
Você pode executar a operação de movimentação usando o ONTAP System Manager, o OnCommand Workflow Automation, comandos do ONTAP ou uma combinação dessas ferramentas.



Após alguns dias, verifique se você está recebendo o mesmo tipo de eventos deste nó ou agregado.
