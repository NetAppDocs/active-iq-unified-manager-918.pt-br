= Analise um evento de desempenho do MetroCluster em um cluster remoto no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode usar o Unified Manager para analisar eventos de desempenho dinâmico em um cluster remoto em uma configuração MetroCluster. A análise ajuda você a determinar se um evento no cluster remoto causou um evento no cluster parceiro.

.Antes de começar
* Você precisa ter a função de Operador, Administrador de Aplicativos ou administrador de storage.
* Você deve ter analisado um evento de desempenho em um cluster local em uma configuração do MetroCluster e obtido o horário de detecção do evento.
* Você deve ter verificado a integridade do cluster local e do cluster parceiro envolvido no evento de desempenho, além de ter obtido o nome do cluster parceiro.


.Passos
. Faça login na instância do Unified Manager que está monitorando o cluster parceiro.
. No painel de navegação à esquerda, clique em *Eventos* para exibir a lista de eventos.
. No seletor *Intervalo de tempo*, selecione *Última hora* e, em seguida, clique em *Aplicar intervalo*.
. No seletor *Filtragem*, selecione *Cluster* no menu suspenso à esquerda, digite o nome do cluster parceiro no campo de texto e clique em *Aplicar filtro*.
+
Se não houver eventos para o cluster selecionado na última hora, isso indica que o cluster não apresentou problemas de desempenho durante o período em que o evento foi detectado em seu parceiro.

. Se o cluster selecionado tiver eventos detectados na última hora, compare o horário de detecção do evento com o horário de detecção do evento no cluster local.
+
Se esses eventos envolverem cargas de trabalho agressoras causando contenção no componente de processamento de dados, uma ou mais dessas cargas agressoras podem ter causado o evento no cluster local. Você pode clicar no evento para analisá-lo e revisar as ações sugeridas para resolvê-lo na página de detalhes do evento.

+
Se esses eventos não envolverem cargas de trabalho excessivas, eles não causaram o evento de desempenho no cluster local.
