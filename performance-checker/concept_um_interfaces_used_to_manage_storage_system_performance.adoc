= Use as interfaces do Active IQ Unified Manager para gerenciar o desempenho do sistema de storage
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Estas seções contêm informações sobre as duas interfaces de usuário que o Active IQ Unified Manager oferece para solucionar problemas de capacidade, disponibilidade e proteção no storage de dados. As duas interfaces de usuário são a interface da Web do Unified Manager e o console de manutenção.

Se você deseja usar os recursos de proteção do Unified Manager, também precisa instalar e configurar o OnCommand Workflow Automation (WFA).



[[unified-manager-web-ui]]
== Interface da Web do Unified Manager

A interface de usuário da web do Unified Manager permite que um administrador monitore e solucione problemas do cluster relacionados à capacidade de storage, disponibilidade e proteção de dados.

Estas seções descrevem alguns fluxos de trabalho comuns que um administrador pode seguir para solucionar problemas de capacidade de storage, disponibilidade de dados ou proteção exibidos na interface web do Unified Manager.



[[maintenance-console]]
== Console de manutenção

O console de manutenção do Unified Manager permite que um administrador monitore, diagnostique e resolva problemas do sistema operacional, problemas de atualização de versão, problemas de acesso de usuários e problemas de rede relacionados ao próprio servidor do Unified Manager. Se a interface web do Unified Manager estiver indisponível, o console de manutenção será a única forma de acesso ao Unified Manager.

Você pode usar essas informações para acessar o console de manutenção e utilizá-las para resolver problemas relacionados ao funcionamento do servidor Unified Manager.
