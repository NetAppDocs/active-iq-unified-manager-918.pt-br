= Edite as políticas de limite de desempenho definidas pelo usuário no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode editar as configurações de limite para políticas de limite de desempenho existentes. Isso pode ser útil se você perceber que está recebendo alertas em excesso ou em falta para determinadas condições de limite.

.Antes de começar
Você precisa ter a função de Application Administrator.

Não é possível alterar o nome da política nem o tipo de objeto de armazenamento monitorado para as políticas de limite existentes.

.Passos
. No painel de navegação esquerdo, selecione *Limiares de eventos* > *Desempenho*.
+
A página Limiares de Desempenho é exibida.

. Selecione a política de limite que deseja alterar e clique em *Editar*.
+
A página Editar política de limite de desempenho é exibida.

. Faça as alterações desejadas na política de limite e clique em *Salvar*.
+
Você volta para a página Limiares de desempenho.



Depois que você as salva, as alterações são aplicadas imediatamente a todos os objetos de armazenamento que usam a política.

Dependendo do tipo de alterações que você fez na política, talvez seja necessário revisar as configurações de alerta definidas para os objetos que usam a política na página Configuração de Alertas.
