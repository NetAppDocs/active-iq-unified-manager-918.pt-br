= Utilize um provedor de identidade no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ao configurar o Unified Manager para usar um provedor de identidade (IdP) para realizar autenticação SAML para todos os usuários remotos, você precisa estar ciente de algumas configurações obrigatórias para que a conexão com Unified Manager seja bem-sucedida.

Você deve inserir o URI e os metadados do Unified Manager no servidor IdP. Você pode copiar essas informações da página SAML Authentication do Unified Manager. O Unified Manager é considerado o provedor de serviços (SP) no padrão Security Assertion Markup Language (SAML).



[[supported-encryption-standards]]
== Padrões de criptografia suportados

* Padrão de Criptografia Avançado (AES): AES-128 e AES-256
* Algoritmo de Hash Seguro (SHA): SHA-1 e SHA-256




[[validated-identity-providers]]
== Provedores de identidade validados

* O Shibboleth
* O Active Directory Federation Services (ADFS)




[[adfs-configuration-requirements]]
== Requisitos de configuração do ADFS

* Você deve definir três regras de declaração na seguinte ordem, que são necessárias para que o Unified Manager analise as respostas SAML do ADFS para esta entrada de confiança da parte confiável.
+
[cols="2*"]
|===
| Regra de reivindicação | Valor 


 a| 
SAM-account-name
 a| 
ID do nome



 a| 
SAM-account-name
 a| 
urn:oid:0.9.2342.19200300.100.1.1



 a| 
Grupos de tokens -- nome não qualificado
 a| 
urn:oid:1.3.6.1.4.1.5923.1.5.1.1

|===
* Você deve definir o método de autenticação como "`Forms Authentication`" ou os usuários poderão receber um erro ao sair do Unified Manager . Siga estas etapas:
+
.. Abra o ADFS Management Console.
.. Clique na pasta Políticas de Autenticação na exibição em árvore à esquerda.
.. Em Ações, à direita, clique em Editar política de autenticação primária global.
.. Defina o método de autenticação da intranet como "`Forms Authentication`" em vez do padrão "`Windows Authentication`".


* Em alguns casos, o login pelo IdP é rejeitado quando o certificado de segurança do Unified Manager é assinado por uma CA. Existem duas soluções alternativas para resolver esse problema:
+
** Siga as instruções indicadas no link para desativar a verificação de revogação no servidor ADFS da parte confiável associada ao certificado de AC encadeada:
+
http://www.torivar.com/2016/03/22/adfs-3-0-disable-revocation-check-windows-2012-r2/["Desativar a verificação de revogação por confiança de parte confiável"]

** Faça com que o servidor CA resida no servidor ADFS para assinar a solicitação de certificado do servidor do Unified Manager.






[[other-configuration-requirements]]
== Outros requisitos de configuração

* O desvio de relógio do Unified Manager está configurado para 5 minutos, portanto a diferença de horário entre o servidor IdP e o servidor Unified Manager não pode ser superior a 5 minutos, caso contrário, a autenticação falhará.
