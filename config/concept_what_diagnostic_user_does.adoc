= Funcionalidades de diagnóstico do usuário no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
O objetivo do acesso para diagnóstico é permitir que o suporte técnico ajude você na solução de problemas, e você só deve usá-lo quando instruído pelo suporte técnico.

O usuário de diagnóstico pode executar comandos no nível do sistema operacional quando orientado pelo suporte técnico, para fins de solução de problemas.
