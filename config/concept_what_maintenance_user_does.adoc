= Saiba mais sobre o usuário de manutenção no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
O usuário de manutenção é criado durante a instalação do Unified Manager em um sistema Red Hat Enterprise Linux. O nome do usuário de manutenção é o usuário "`umadmin`". O usuário de manutenção tem a função Application Administrator na IU da web, e esse usuário pode criar usuários subsequentes e atribuir funções a eles.

O usuário de manutenção, ou usuário umadmin, também pode acessar o console de manutenção do Unified Manager.
