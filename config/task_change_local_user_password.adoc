= Alterar a senha do usuário local no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode alterar a senha de login do seu usuário local para evitar possíveis riscos de segurança.

.Antes de começar
Você precisa estar conectado como um usuário local.

As senhas do usuário de manutenção e dos usuários remotos não podem ser alteradas seguindo estas etapas. Para alterar a senha de um usuário remoto, entre em contato com seu administrador de senhas. Para alterar a senha do usuário de manutenção, consulte link:task_use_maintenance_console.html["Usando o console de manutenção"].

.Passos
. Faça login no Unified Manager.
. Na barra de menu superior, clique no ícone do usuário e em seguida clique em *Alterar senha*.
+
A opção *Change Password* não é exibida se você for um usuário remoto.

. Na caixa de diálogo Change Password, insira a senha atual e a nova senha.
. Clique em *Salvar*.


Se o Unified Manager estiver configurado em uma configuração de alta disponibilidade, você deverá alterar a senha no segundo nó da configuração. Ambas as instâncias devem ter a mesma senha.
