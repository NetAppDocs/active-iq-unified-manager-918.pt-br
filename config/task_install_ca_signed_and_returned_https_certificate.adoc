= Instale um certificado HTTPS assinado por uma Autoridade Certificadora (CA) no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode fazer upload e instalar um certificado de segurança depois que uma Autoridade Certificadora (AC) o assinar e devolver. O arquivo que você faz upload e instala deve ser uma versão assinada do certificado autoassinado existente. Um certificado assinado por uma AC ajuda a evitar ataques "man-in-the-middle" e oferece melhor proteção de segurança do que um certificado autoassinado.

*O que. Antes de começar

Você deve ter concluído as seguintes ações:

* Baixou o arquivo de solicitação de assinatura de certificado e o enviou para assinatura por uma autoridade certificadora
* Salvou a cadeia de certificados no formato PEM
* Inclui todos os certificados na cadeia, do certificado do servidor do Unified Manager até o certificado raiz de assinatura, incluindo quaisquer certificados intermediários presentes


Você precisa ter a função de Application Administrator.

[NOTE]
====
Se a validade do certificado para o qual um CSR foi criado for superior a 397 dias, a CA reduzirá essa validade para 397 dias antes de assinar e devolver o certificado

====
.Passos
. No painel de navegação esquerdo, clique em *Geral* > *Certificado HTTPS*.
. Clique em *Instalar certificado HTTPS*.
. Na caixa de diálogo que aparece, clique em *Escolher arquivo...* para localizar o arquivo que deseja carregar.
. Selecione o arquivo e clique em *Instalar* para instalar o arquivo.
+
Para informações, consulte link:concept_install_https_certificate_generated_using_external_tools.html["Instalando um certificado HTTPS gerado com ferramentas externas"].

-----BEGIN CERTIFICATE-----
<*Server certificate*>
-----END CERTIFICATE-----
-----BEGIN CERTIFICATE-----
<*Intermediate certificate \#1 (if present)*>
-----END CERTIFICATE-----
-----BEGIN CERTIFICATE-----
<*Intermediate certificate \#2 (if present)*>
-----END CERTIFICATE-----
-----BEGIN CERTIFICATE-----
<*Root signing certificate*>
-----END CERTIFICATE-----
----
