= Execute a configuração inicial da interface web do Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Para usar o Unified Manager, você deve primeiro configurar as opções de configuração inicial, incluindo o servidor NTP, o endereço de e-mail do usuário de manutenção, o host do servidor SMTP e a adição de clusters do ONTAP.

.Antes de começar
Você deve ter realizado as seguintes operações:

* Iniciou a interface da web do Unified Manager usando a URL fornecida após a instalação
* Você fez login usando o nome de usuário e a senha de manutenção (usuário umadmin para instalações Linux) criados durante a instalação


A página Active IQ Unified ManagerGetting Started aparece somente quando você acessa a interface web pela primeira vez. A página abaixo é de uma instalação no VMware.

image::../media/first_experience_wizard.JPG[Uma captura de tela da interface de usuário que mostra uma página da instalação no VMware.]

Se quiser alterar qualquer uma dessas opções posteriormente, você poderá selecionar sua escolha nas opções Gerais no painel de navegação à esquerda do Unified Manager. Observe que a configuração de NTP é exclusiva para instalações VMware e pode ser alterada posteriormente usando o console de manutenção do Unified Manager.

.Passos
. Na página de Configuração Inicial do Active IQ Unified Manager, insira o endereço de e-mail do usuário de manutenção, o nome do host do servidor SMTP, quaisquer opções adicionais de SMTP e o servidor NTP (somente para instalações VMware). Em seguida, clique em *Continuar*.
+
[NOTE]
====
Se você selecionou a opção *Usar STARTTLS* ou *Usar SSL*, uma página de certificado é exibida após clicar no botão *Continuar*. Verifique os detalhes do certificado e aceite-o para prosseguir com as configurações iniciais da interface web.

====
. Na página AutoSupport, clique em *Agree and Continue* para habilitar o envio de mensagens de AutoSupport do Unified Manager para o NetAppActive IQ.
+
Se você precisar designar um proxy para fornecer acesso à internet para enviar conteúdo do AutoSupport, ou se quiser desativar o AutoSupport, use a opção *Geral* > *AutoSupport* na interface da web.

. Em sistemas Red Hat, altere a senha do usuário umadmin da string padrão "`admin`" para uma string personalizada.
. Na página Configurar Gateway de API, selecione se deseja usar o recurso Gateway de API que permite ao Unified Manager gerenciar os clusters do ONTAP que você planeja monitorar usando as APIs REST do ONTAP. Em seguida, clique em *Continuar*.
+
Você pode ativar ou desativar essa configuração posteriormente na interface da web em *Geral* > *Configurações de recursos* > *Gateway de API*. Para obter mais informações sobre as APIs, consulte link:../api-automation/concept_get_started_with_um_apis.html["Primeiros passos com as APIs REST do Active IQ Unified Manager"].

. Adicione os clusters que você deseja que o Unified Manager gerencie e clique em *Avançar*. Para cada cluster que você planeja gerenciar, você deve ter o nome do host ou o endereço IP de gerenciamento do cluster (IPv4 ou IPv6), juntamente com o nome de usuário e as credenciais de senha; o usuário deve ter a função "`admin`".
+
Esta etapa é opcional. Você pode adicionar clusters posteriormente na interface de usuário da web em *Gerenciamento de armazenamento* > *Configuração de cluster*.

. Na página de resumo, verifique se todas as configurações estão corretas e clique em *Concluir*.


A página de introdução é fechada e a página Dashboard do Unified Manager é exibida.
