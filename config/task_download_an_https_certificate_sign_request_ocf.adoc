= Faça o download de uma solicitação de assinatura de certificado HTTPS no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode baixar uma solicitação de assinatura de certificado para o certificado de segurança HTTPS atual para que você possa fornecer o arquivo a uma Autoridade Certificadora (AC) para assiná-lo. Um certificado assinado por uma AC ajuda a evitar ataques do tipo "man-in-the-middle" e oferece melhor proteção de segurança do que um certificado autoassinado.

.Antes de começar
Você precisa ter a função de Application Administrator.

.Passos
. No painel de navegação esquerdo, clique em *Geral* > *Certificado HTTPS*.
. Clique em *Baixar Solicitação de Assinatura de Certificado HTTPS*.
. Salve o `<hostname>.csr` arquivo.


Você pode fornecer o arquivo a uma autoridade de certificação para que ela o assine e, em seguida, instale o certificado assinado.
