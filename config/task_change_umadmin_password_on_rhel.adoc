= Altere a senha umadmin do Active IQ Unified Manager em sistemas Linux
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Por motivos de segurança, você deve alterar a senha padrão do usuário umadmin do Unified Manager imediatamente após concluir o processo de instalação. Se necessário, você poderá alterar a senha novamente a qualquer momento.

.Antes de começar
* O Unified Manager deve ser instalado em um sistema Red Hat Enterprise Linux.
* Você deve ter as credenciais do usuário raiz do sistema Linux no qual o Unified Manager está instalado.


.Passos
. Faça login como usuário raiz no sistema Linux em que o Unified Manager está em execução.
. Altere a senha do umadmin:
+
`passwd umadmin`

+
O sistema solicita que você insira uma nova senha para o usuário umadmin.
