= Altere a senha do usuário de manutenção no Windows no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode alterar a senha do usuário de manutenção do Unified Manager quando necessário.

.Passos
. Na página de login da interface web do Unified Manager, clique em *Esqueci minha senha*.
+
Uma página é exibida solicitando o nome do usuário cuja senha você deseja redefinir.

. Digite o nome de usuário e clique em *Enviar*.
+
Um e-mail com um link para redefinir a senha é enviado ao endereço de e-mail definido para esse nome de usuário.

. Clique no *link de redefinição de senha* no e-mail e defina a nova senha.
. Retorne à interface web e faça login no Unified Manager usando a nova senha.
