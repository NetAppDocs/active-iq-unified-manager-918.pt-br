= Acesse a interface web no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Após instalar o Unified Manager, você poderá acessar a interface de usuário da web para configurar o Unified Manager e começar a monitorar seus sistemas ONTAP.

.Antes de começar
* Se esta for a primeira vez que você está acessando a interface de usuário da web, você deve fazer login como o usuário de manutenção (ou o usuário umadmin para instalações do Linux).
* Se você planeja permitir que os usuários acessem o Unified Manager usando o nome curto em vez de usar o domínio totalmente qualificado (FQDN) ou o endereço IP, sua configuração de rede precisa resolver esse nome curto para um FQDN válido.
* Se o servidor usar um certificado digital autoassinado, o navegador poderá exibir um aviso indicando que o certificado não é confiável. Você pode aceitar o risco para continuar acessando ou instalar um certificado digital assinado por uma Autoridade Certificadora (CA) para autenticação do servidor.


.Passos
. Inicie a interface web do Unified Manager no seu navegador usando a URL exibida no final da instalação. A URL é o endereço IP ou o nome de domínio totalmente qualificado (FQDN) do servidor Unified Manager.
+
O link está no seguinte formato: `\https://URL`.

. Faça login na interface da web do Unified Manager usando suas credenciais de usuário de manutenção.



NOTE: Se você fizer três tentativas consecutivas sem sucesso de login na interface de usuário da web em uma hora, seu acesso ao sistema será bloqueado, e você precisará entrar em contato com o administrador do sistema. Isso se aplica somente a usuários locais.
