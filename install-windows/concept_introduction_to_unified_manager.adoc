= Saiba mais sobre o Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
O Active IQ Unified Manager (formerly OnCommand Unified Manager) permite que você monitore e gerencie a integridade e o desempenho dos seus sistemas de storage ONTAP a partir de uma única interface. Você pode implantar o Unified Manager em um servidor Linux, em um servidor Windows ou como um dispositivo virtual em um host VMware.

Após concluir a instalação e adicionar os clusters que deseja gerenciar, o Unified Manager fornece uma interface gráfica que exibe a capacidade, a disponibilidade, a proteção e o status de desempenho dos sistemas de armazenamento monitorados.
