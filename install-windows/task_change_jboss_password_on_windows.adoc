= Altere a senha do JBoss no Windows no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode redefinir a senha específica da instância do JBoss, definida durante a instalação. Opcionalmente, você pode redefinir a senha caso seu site exija esse recurso de segurança para substituir a configuração de instalação do Unified Manager. Essa operação também altera a senha que o JBoss usa para acessar o MySQL.

.Antes de começar
* Você deve ter privilégios de administrador do Windows no sistema em que o Unified Manager está instalado.
* Você deve ter a senha do usuário raiz do MySQL.
* Você deverá conseguir acessar o script fornecido pela NetApp `password.bat` no diretório
+
`C:\Program Files\NetApp\essentials\bin`.



.Passos
. Faça login como usuário administrador na máquina host do Unified Manager.
. Use o console de Serviços do Windows para interromper os seguintes serviços do Unified Manager:
+
** Serviço de aquisição do NetApp Active IQ (Ocie-au)
** Serviço NetApp Active IQ Management Server (Oncommandsvc)


. Execute o `password.bat` script para iniciar o processo de alteração de senha:
+
`C:\Program Files\NetApp\essentials\bin> password.bat resetJBossPassword`

. Quando solicitado, insira a senha do usuário raiz do MySQL.
. Quando solicitado, insira a nova senha de usuário do JBoss e, em seguida, insira-a novamente para confirmação.
+
Observe que a senha deve ter entre 8 e 16 caracteres e deve conter pelo menos um dígito, uma letra maiúscula, uma letra minúscula e pelo menos um destes caracteres especiais:

+
`+!@%^*-_+=[]:<>.?/~+`

. Quando o script for concluído, inicie os serviços do Unified Manager usando o console de Serviços do Windows:
+
** Serviço NetApp Active IQ Management Server (Oncommandsvc)
** Serviço de aquisição do NetApp Active IQ (Ocie-au)


. Após todos os serviços serem iniciados, você poderá fazer login na interface do usuário do Unified Manager.
