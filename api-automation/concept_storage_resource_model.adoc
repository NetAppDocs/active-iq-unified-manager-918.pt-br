= Entenda o modelo de recursos de armazenamento do ONTAP no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Os recursos de storage no ONTAP podem ser amplamente classificados em _recursos de storage físico_ e _recursos de storage lógico._ Para gerenciar seus sistemas ONTAP de forma eficaz usando as APIs fornecidas no Active IQ Unified Manager, você deve compreender o modelo de recursos de storage e a relação entre os vários recursos de storage.

* *Recursos de storage físico*
+
Refere-se aos objetos de storage físico fornecidos pelo ONTAP. Os recursos de storage físico incluem discos, clusters, controladores de storage, nós e agregados.

* *Recursos lógicos de storage*
+
Refere-se aos recursos de storage fornecidos pelo ONTAP que não estão vinculados a um recurso físico. Esses recursos estão associados a uma máquina virtual de storage (SVM, anteriormente conhecida como Vserver) e existem independentemente de qualquer recurso específico de storage físico, como um disco, uma LUN de array ou um agregado.

+
Os recursos de storage lógico incluem volumes de todos os tipos e qtrees, bem como os recursos e as configurações que você pode usar com esses recursos, como cópias Snapshot, deduplicação, compactação e cotas.
