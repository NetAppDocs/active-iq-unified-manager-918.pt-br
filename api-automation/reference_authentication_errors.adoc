= Saiba mais sobre os códigos de status HTTP do Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ao executar as APIs ou solucionar problemas, você deve estar ciente dos vários códigos de status HTTP e códigos de erro usados pelas APIs do Active IQ Unified Manager.

A tabela a seguir lista os códigos de erro relacionados à autenticação:

[cols="3*"]
|===
| Código de status HTTP | Título do código de status | Descrição 


 a| 
200
 a| 
OK
 a| 
Retornado após a execução bem-sucedida de chamadas de API síncronas.



 a| 
201
 a| 
Criado
 a| 
Criação de novos recursos por meio de chamadas síncronas, como a configuração do Active Directory.



 a| 
202
 a| 
Aceito
 a| 
Retornado após a execução bem-sucedida de chamadas assíncronas para funções de provisionamento, como a criação de LUNs e compartilhamentos de arquivos.



 a| 
400
 a| 
Solicitação inválida
 a| 
Indica falha na validação de entrada. Você precisa corrigir as entradas, por exemplo, chaves válidas no corpo da requisição.



 a| 
401
 a| 
Solicitação não autorizada
 a| 
Você não está autorizado a visualizar o recurso/Não autorizado.



 a| 
403
 a| 
Solicitação proibida
 a| 
O acesso ao recurso que você estava tentando acessar é proibido.



 a| 
404
 a| 
Recurso não encontrado
 a| 
O recurso que você estava tentando acessar não foi encontrado.



 a| 
405
 a| 
Método não permitido
 a| 
Método não permitido.



 a| 
429
 a| 
Muitas solicitações
 a| 
Retornado quando o usuário envia muitas solicitações dentro de um período específico.



 a| 
500
 a| 
Erro interno do servidor
 a| 
Erro interno do servidor. Falha ao obter a resposta do servidor. Esse erro interno do servidor pode ou não ser permanente. Por exemplo, se você executar uma `GET` ou `GET ALL` operação e receber esse erro, é recomendável repetir essa operação no mínimo cinco vezes. Se for um erro permanente, o código de status retornado continuará a ser 500. Se a operação for bem-sucedida, o código de status retornado será 200.

|===
