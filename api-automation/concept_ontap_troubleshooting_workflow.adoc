= Solucione problemas dos volumes ONTAP usando as APIs de gateway do Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
As APIs de gateway atuam como uma porta de entrada para invocar as APIs do ONTAP, consultar informações sobre seus objetos de armazenamento do ONTAP e tomar medidas corretivas para solucionar os problemas relatados.

Este fluxo de trabalho aborda um exemplo de caso de uso em que um evento é acionado quando um volume do ONTAP quase atinge sua capacidade. O fluxo de trabalho também demonstra como resolver esse problema invocando uma combinação das APIs REST do Active IQ Unified Manager e do ONTAP.

[NOTE]
====
Antes de executar as etapas do fluxo de trabalho, certifique-se do seguinte:

* Você está ciente das APIs do gateway e de como elas são usadas. Para obter informações, consulte link:concept_gateway_apis.html["Acesso às APIs do ONTAP por meio de acesso por proxy"].
* Você conhece o uso das APIs REST do ONTAP. Para obter informações sobre como usar as APIs REST do ONTAP, consulte https://docs.netapp.com/us-en/ontap-automation/index.html["Documentação de automação do ONTAP"].
* Você é um administrador de aplicativos.
* O cluster no qual você deseja executar as operações da API REST é compatível com o ONTAP 9.5 ou posterior, e você adiciona o cluster ao Unified Manager via HTTPS.


====
O diagrama a seguir ilustra cada etapa do fluxo de trabalho para solucionar o problema de uso da capacidade do volume do ONTAP.

image::../media/api_gateway_ontap_workflow.gif[Um diagrama que mostra o Unified Manager e o ONTAP, com as etapas da API para solucionar problemas de alertas de capacidade de volume]

O fluxo de trabalho abrange os pontos de invocação das APIs REST do Unified Manager e do ONTAP.

. Anote o nome do volume no evento que notifica a utilização da capacidade do volume.
. Utilizando o nome do volume como valor no parâmetro `name`, consulte o volume executando a seguinte API do Unified Manager.
+
[cols="3*"]
|===
| Categoria | Verbo HTTP | Caminho 


 a| 
data center
 a| 
GET
 a| 
`/datacenter/storage/volumes`

|===
. Recupere o UUID do cluster e o UUID do volume da saída.
. Na interface do usuário da web do Unified Manager, navegue até *General* > *Feature Settings* > *API Gateway* para verificar se o recurso API Gateway está habilitado. A menos que ele esteja habilitado, as APIs na categoria gateway não estarão disponíveis para você invocar. Habilite o recurso se ele estiver desabilitado.
. Utilize o UUID do cluster para executar a API ONTAP /`storage/volumes/{uuid}` por meio do gateway de API. A consulta retorna os detalhes do volume quando o UUID do volume é passado como parâmetro da API.
+
Para executar as APIs do ONTAP pelo gateway de API, as credenciais do Unified Manager são passadas internamente para autenticação, e você não precisa executar uma etapa adicional de autenticação para acesso a clusters individuais.

+
[cols="3*"]
|===
| Categoria | Verbo HTTP | Caminho 


 a| 
O Unified Manager: gateway

ONTAP: armazenamento
 a| 
GET
 a| 
A API Gateway: `/gateways/\{uuid}/\{path}`

API ONTAP: `/storage/volumes/\{uuid}`

|===
+
[NOTE]
====
Em /gateways/\{uuid}/\{path}, o valor de \{uuid} deve ser substituído pelo UUID do cluster no qual a operação da API REST deve ser realizada. \{path} deve ser substituído pelo URL REST do ONTAP /storage/volumes/\{uuid}.

====
+
A URL anexada é: `/gateways/\{cluster_uuid}/storage/volumes/\{volume_uuid}`

+
Ao executar a operação GET, a URL gerada é: `GEThttps://<hostname\>/api/gateways/<cluster_UUID\>/storage/volumes/\{volume_uuid\}`

+
*Exemplo de comando cURL*

+
[listing]
----
curl -X GET "https://<hostname>/api/gateways/1cd8a442-86d1-11e0-ae1c-9876567890123/storage/volumes/028baa66-41bd-11e9-81d5-00a0986138f7"
-H "accept: application/hal+json" -H "Authorization: Basic <Base64EncodedCredentials>"
----
. A partir da saída, determine o tamanho, o uso e a medida corretiva a ser tomada. Neste fluxo de trabalho, a medida corretiva tomada é o redimensionamento do volume.
. Use o UUID do cluster e execute a seguinte API do ONTAP por meio do gateway de API para redimensionar o volume. Para obter informações sobre os parâmetros de entrada para as APIs do gateway e do ONTAP, consulte a etapa 5.
+
[cols="3*"]
|===
| Categoria | Verbo HTTP | Caminho 


 a| 
O Unified Manager: gateway

ONTAP: armazenamento
 a| 
PATCH
 a| 
A API Gateway: `/gateways/\{uuid}/\{path}`

API ONTAP: `/storage/volumes/\{uuid}`

|===
+
[NOTE]
====
Juntamente com o UUID do cluster e o UUID do volume, você deve inserir um valor para o parâmetro size para redimensionar o volume. Certifique-se de inserir o valor _em bytes_. Por exemplo, se você quiser aumentar o tamanho de um volume de 100 GB para 120 GB, insira o valor do parâmetro size no final da consulta: `-d {\"size\": 128849018880}"`

====
+
*Exemplo de comando cURL*

+
[listing]
----
curl -X PATCH "https://<hostname>/api/gateways/1cd8a442-86d1-11e0-ae1c-9876567890123/storage/volumes/028baa66-41bd-11e9-81d5-00a0986138f7" -H
    "accept: application/hal+json" -H "Authorization: Basic <Base64EncodedCredentials>" -d
    {\"size\": 128849018880}"
----
+
A saída JSON retorna um UUID de tarefa.

. Verifique se a tarefa foi executada com sucesso usando o UUID da tarefa. Use o UUID do cluster e o UUID da tarefa para executar a seguinte API do ONTAP por meio do gateway de API. Para obter informações sobre os parâmetros de entrada das APIs do gateway e do ONTAP, consulte a etapa 5.
+
[cols="3*"]
|===
| Categoria | Verbo HTTP | Caminho 


 a| 
O Unified Manager: gateway

O ONTAP: cluster
 a| 
GET
 a| 
A API Gateway: `/gateways/\{uuid}/\{path}`

API do ONTAP: `/cluster/jobs/\{uuid}`

|===
+
Os códigos HTTP retornados são os mesmos códigos de status HTTP da API REST do ONTAP.

. Execute a seguinte API ONTAP para consultar os detalhes do volume redimensionado. Para obter informações sobre os parâmetros de entrada para as APIs de gateway e ONTAP, consulte a etapa 5.
+
[cols="3*"]
|===
| Categoria | Verbo HTTP | Caminho 


 a| 
O Unified Manager: gateway

ONTAP: armazenamento
 a| 
GET
 a| 
A API Gateway: `/gateways/\{uuid}/\{path}`

API ONTAP: `/storage/volumes/\{uuid}`

|===
+
A saída exibe um tamanho de volume aumentado de 120 GB.
