= Acesse e autentique APIs REST no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]

** `_IP address/hostname_` é o endereço IP ou o nome de domínio totalmente qualificado (FQDN) do servidor da API.
** Porta 443
+
443 é a porta HTTPS padrão. Você pode personalizar a porta HTTPS, se necessário.



+
Para enviar solicitações HTTP a partir de um navegador web, você precisa usar plug-ins de navegador para API REST. Você também pode acessar a API REST usando plataformas de script como cURL e Perl.





[[authentication]]
== Autenticação

O Unified Manager suporta o esquema básico de autenticação HTTP para APIs. Para garantir um fluxo seguro de informações (solicitação e resposta), as APIs REST são acessíveis somente via HTTPS. O servidor da API fornece um certificado SSL autoassinado a todos os clientes para verificação do servidor. Esse certificado pode ser substituído por um certificado personalizado (ou certificado de CA).

Você deve configurar o acesso do usuário ao servidor da API para invocar as APIs REST. Os usuários podem ser usuários locais (perfis de usuário armazenados no banco de dados local) ou usuários LDAP (se você tiver configurado o servidor da API para autenticar via LDAP). Você pode gerenciar o acesso do usuário fazendo login na interface de usuário do console de administração do Unified Manager.
