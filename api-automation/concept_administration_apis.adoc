= Execute tarefas administrativas usando APIs no Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode usar as APIs na categoria  `administration` para modificar as configurações de backup, verificar as informações do arquivo de backup e os certificados do cluster, além de gerenciar clusters ONTAP como fontes de dados do Active IQ Unified Manager.

[NOTE]
====
Você precisa ter a função de Administrador de Aplicativos para executar essas operações. Você também pode usar a interface web do Unified Manager para configurar essas configurações.

====
[cols="3*"]
|===
| Verbo HTTP | Caminho | Descrição 


 a| 
`GET`

`PATCH`
 a| 
`/admin/backup-settings`

`/admin/backup-settings`
 a| 
Você pode usar o `GET` método para visualizar as configurações do agendamento de backup configurado no Unified Manager por padrão. Você pode verificar o seguinte:

* Se o agendamento está ativado ou desativado
* Frequência do backup agendado (diário ou semanal)
* Hora do backup
* Número máximo de arquivos de backup que devem ser mantidos no aplicativo


O horário do backup está no fuso horário do servidor.

As configurações de backup do banco de dados estão disponíveis no Unified Manager por padrão, e você não pode criar um agendamento de backup. No entanto, você pode usar o  `PATCH`método para modificar as configurações padrão.



 a| 
`GET`
 a| 
`/admin/backup-file-info`
 a| 
Um arquivo de dump de backup é gerado sempre que a programação de backup é modificada para o Unified Manager. Você pode usar esse método para verificar se o arquivo de backup é gerado de acordo com as configurações de backup modificadas e se as informações no arquivo correspondem às configurações modificadas.



 a| 
`GET`
 a| 
`/admin/datasource-certificate`
 a| 
Você pode usar este método para visualizar o certificado da fonte de dados (cluster) no repositório de confiança. A validação do certificado é necessária antes de adicionar um cluster ONTAP como uma fonte de dados do Unified Manager.



 a| 
`GET`

`POST`

`PATCH`

`DELETE`
 a| 
`/admin/datasources/clusters`

`/admin/datasources/clusters/\{key}`
 a| 
Você pode usar o `GET` método para recuperar os detalhes das fontes de dados (clusters do ONTAP) gerenciadas pelo Unified Manager.

Você também pode adicionar um novo cluster ao Unified Manager como uma fonte de dados. Para adicionar um cluster, você precisa saber o nome do host, o nome de usuário e a senha.

Para modificar e excluir um cluster gerenciado como fonte de dados pelo Unified Manager, use a chave do cluster ONTAP.

|===
