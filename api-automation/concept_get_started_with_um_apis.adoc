= Comece a usar as APIs REST do Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
O Active IQ Unified Manager fornece um conjunto de APIs para gerenciar seus recursos de storage nos sistemas de armazenamento compatíveis por meio de uma interface de serviço web RESTful para qualquer integração de terceiros.

Nestes tópicos, você encontrará informações sobre as APIs do Unified Manager, fluxos de trabalho de exemplo para resolver problemas específicos e alguns códigos de exemplo. Com essas informações, você pode criar clientes RESTful de soluções de software de capacidade de gerenciamento da NetApp para gerenciar sistemas NetApp. As APIs são baseadas no estilo arquitetural Representational State Transfer (REST). Há suporte para todas as quatro operações REST: create, read, update e delete (também conhecidas como CRUD).

Consulte link:https://docs.netapp.com/us-en/netapp-automation/api/aiqum.html["Active IQ Unified Manager"^] para ver recursos adicionais e detalhes sobre os benefícios da API REST do Active IQ Unified Manager.
