= Provisione compartilhamentos de arquivos CIFS e NFS usando as APIs do Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode provisionar compartilhamentos CIFS e compartilhamentos de arquivos NFS em suas Máquinas Virtuais de Armazenamento (SVMs) usando as APIs de provisionamento fornecidas como parte do Active IQ Unified Manager. Este fluxo de trabalho de provisionamento detalha as etapas para recuperar as chaves das SVMs, os Níveis de Serviço de Desempenho e as Políticas de Eficiência de Armazenamento antes de criar os compartilhamentos de arquivos.

O diagrama a seguir ilustra cada etapa em um fluxo de trabalho de provisionamento de compartilhamento de arquivos. Ele inclui o provisionamento de compartilhamentos CIFS e compartilhamentos de arquivos NFS.

image::../media/create_fileshares.gif[Um diagrama que mostra um fluxo de trabalho de provisionamento de compartilhamento de arquivos CIFS e NFS, desde a configuração do SVM até a criação do compartilhamento]

[NOTE]
====
Certifique-se do seguinte:

* Os clusters ONTAP foram adicionados ao Unified Manager, e a chave do cluster foi obtida.
* As SVMs foram criadas nos clusters.
* Os SVMs suportam os serviços CIFS e NFS. O provisionamento de compartilhamentos de arquivos pode falhar se os SVMs não suportarem os serviços necessários.
* A porta FCP está online para provisionamento de porta.


====
. Verifique se as LIFs de dados ou os endpoints de acesso estão disponíveis na SVM na qual você deseja criar o compartilhamento CIFS. Obtenha a lista de endpoints de acesso disponíveis na SVM:
+
[cols="3*"]
|===
| Categoria | Verbo HTTP | Caminho 


 a| 
provedor de armazenamento
 a| 
GET
 a| 
`/storage-provider/access-endpoints`
`/storage-provider/access-endpoints/\{key}`

|===
+
*Exemplo de cURL*

+
[listing]
----
curl -X GET "https://<hostname>/api/storage-provider/access-endpoints?resource.key=7d5a59b3-953a-11e8-8857-00a098dcc959" -H "accept: application/json" -H "Authorization: Basic <Base64EncodedCredentials>"
----
. Se o seu endpoint de acesso estiver disponível na lista, obtenha a chave do endpoint de acesso, caso contrário, crie o endpoint de acesso.
+
[NOTE]
====
Certifique-se de criar endpoints de acesso com o protocolo CIFS habilitado. O provisionamento de compartilhamentos CIFS falhará, a menos que você tenha criado um endpoint de acesso com o protocolo CIFS habilitado.

====

provedor de armazenamento
 a| 
POST
 a| 
`/storage-provider/access-endpoints`

|===
+
*Exemplo de cURL*

+

. Determine se você precisa criar um compartilhamento CIFS ou um compartilhamento de arquivos NFS. Para criar compartilhamentos CIFS, siga estas subetapas:
+
.. Verifique se o servidor CIFS está configurado na sua SVM, ou seja, verifique se há um mapeamento do Active Directory criado na SVM.
+
[cols="3*"]
|===
| Categoria | Verbo HTTP | Caminho 


 a| 
provedor de armazenamento
 a| 
GET
 a| 
`/storage-provider/active-directories-mappings`

|===
.. Se o mapeamento do Active Directory estiver criado, use a chave; caso contrário, crie o mapeamento do Active Directory na SVM.
+
[cols="3*"]
|===
| Categoria | Verbo HTTP | Caminho 


 a| 
provedor de armazenamento
 a| 
POST
 a| 
`/storage-provider/active-directories-mappings`

|===
+
*Exemplo de cURL*

+
Você deve inserir os detalhes para criar o mapeamento do Active Directory nos parâmetros de entrada.

+
[listing]
----
curl -X POST "https://<hostname>/api/storage-provider/active-directories-mappings" -H "accept: application/json" -H "Content-Type: application/json" -H "Authorization: Basic <Base64EncodedCredentials>"
{ \"_links\": {},
\"dns\": \"10.000.000.000\",
\"domain\": \"example.com\",
\"password\": \"string\",
\"svm\": { \"key\": \"9f4ddea-e395-11e9-b660-005056a71be9:type=vserver,uuid=191a554a-f0ce-11e9-b660-005056a71be9\" },
\"username\": \"string\"}"
----
+
Esta é uma chamada síncrona e você pode verificar a criação do mapeamento do Active Directory na saída. Em caso de erro, a mensagem de erro é exibida para que você possa solucionar o problema e executar a solicitação novamente.



. Obtenha a chave da SVM na qual você deseja criar o compartilhamento CIFS ou o compartilhamento de arquivos NFS, conforme descrito no tópico do fluxo de trabalho _Verifying SVMs on clusters_.
. Obtenha a chave do nível de serviço de desempenho executando a seguinte API e recuperando a chave da resposta.
+
[cols="3*"]
|===
| Categoria | Verbo HTTP | Caminho 


 a| 
provedor de armazenamento
 a| 
GET
 a| 
`/storage-provider/performance-service-levels`

|===
+
[NOTE]
====
Você pode recuperar os detalhes dos Níveis de Serviço de Desempenho definidos pelo sistema configurando o `system_defined` parâmetro de entrada como `true`. Na saída, obtenha a chave do Nível de Serviço de Desempenho que você deseja aplicar ao compartilhamento de arquivos.

====
. Opcionalmente, obtenha a chave da Política de eficiência de storage que você deseja aplicar ao compartilhamento de arquivos executando a seguinte API e recuperando a chave da resposta.
+
[cols="3*"]
|===
| Categoria | Verbo HTTP | Caminho 


 a| 
provedor de armazenamento
 a| 
GET
 a| 
`/storage-provider/storage-efficiency-policies`

|===
. Crie o compartilhamento de arquivos. Você pode criar um compartilhamento de arquivos que suporte CIFS e NFS especificando a lista de controle de acesso e a política de exportação. As subetapas a seguir fornecem informações caso você queira criar um compartilhamento de arquivos para oferecer suporte a apenas um dos protocolos no volume. Você também pode atualizar um compartilhamento de arquivos NFS para incluir a lista de controle de acesso após criar o compartilhamento NFS. Para obter informações, consulte o tópico _Modifying storage workloads_.
+
.. Para criar apenas um compartilhamento CIFS, reúna as informações sobre a lista de controle de acesso (ACL). Para criar o compartilhamento CIFS, forneça valores válidos para os seguintes parâmetros de entrada. Para cada grupo de usuários que você atribuir, uma ACL é criada quando um compartilhamento CIFS/SMB é provisionado. Com base nos valores inseridos para ACL e mapeamento do Active Directory, o controle de acesso e o mapeamento são definidos para o compartilhamento CIFS quando ele é criado.
+
*Um comando cURL com valores de exemplo*

+
[listing]
----
{
  "access_control": {
    "acl": [
      {
        "permission": "read",
        "user_or_group": "everyone"
      }
    ],
    "active_directory_mapping": {
      "key": "3b648c1b-d965-03b7-20da-61b791a6263c"
    },
----
.. Para criar apenas um compartilhamento de arquivos NFS, reúna as informações sobre a política de exportação. Para criar o compartilhamento de arquivos NFS, forneça valores válidos para os seguintes parâmetros de entrada. Com base nos seus valores, a política de exportação é anexada ao compartilhamento de arquivos NFS quando ele é criado.
+
[NOTE]
====
Ao provisionar o compartilhamento NFS, você pode criar uma política de exportação fornecendo todos os valores necessários ou fornecer a chave da política de exportação e reutilizar uma política de exportação existente. Se você quiser reutilizar uma política de exportação para a VM de storage, precisará adicionar a chave da política de exportação. A menos que você conheça a chave, pode recuperar a chave da política de exportação usando a `/datacenter/protocols/nfs/export-policies` API. Para criar uma nova política, você deve inserir as regras conforme mostrado no exemplo a seguir. Para as regras inseridas, a API tenta procurar uma política de exportação existente correspondendo ao host, à VM de storage e às regras. Se houver uma política de exportação existente, ela será usada. Caso contrário, uma nova política de exportação será criada.

====
+
*Um comando cURL com valores de exemplo*

+
[listing]
----
"export_policy": {
      "key": "7d5a59b3-953a-11e8-8857-00a098dcc959:type=export_policy,uuid=1460288880641",
      "name_tag": "ExportPolicyNameTag",
      "rules": [
        {
          "clients": [
            {
              "match": "0.0.0.0/0"
            }
----


+
