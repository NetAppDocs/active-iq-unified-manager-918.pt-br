= Modifique um compartilhamento de arquivos NFS para suportar CIFS usando as APIs do Active IQ Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode modificar um compartilhamento de arquivos NFS para oferecer suporte ao protocolo CIFS. Durante a criação do compartilhamento de arquivos, é possível especificar os parâmetros da lista de controle de acesso (ACL) e as regras da política de exportação para o mesmo compartilhamento de arquivos. No entanto, se você quiser habilitar CIFS no mesmo volume em que criou um compartilhamento de arquivos NFS, poderá atualizar os parâmetros de ACL desse compartilhamento de arquivos para oferecer suporte a CIFS.

.Antes de começar
. É necessário criar um compartilhamento de arquivos NFS contendo apenas os detalhes da política de exportação. Para obter mais informações, consulte _Gerenciando compartilhamentos de arquivos_ e _Modificando cargas de trabalho de armazenamento_.
. Você precisa da chave do compartilhamento de arquivos para executar esta operação. Para obter informações sobre como visualizar os detalhes do compartilhamento de arquivos e recuperar a chave do compartilhamento de arquivos usando o ID da tarefa, consulte _Provisionamento de compartilhamentos de arquivos CIFS e NFS_.


Isso se aplica a um compartilhamento de arquivos NFS que você criou adicionando apenas regras de política de exportação, e não parâmetros de ACL. Você modifica o compartilhamento de arquivos NFS para incluir os parâmetros de ACL.

.Passos
. No compartilhamento de arquivos NFS, execute uma `PATCH` operação com os detalhes da ACL para permitir o acesso CIFS.
+
[cols="3*"]
|===
| Categoria | Verbo HTTP | Caminho 


 a| 
provedor de armazenamento
 a| 
PATCH
 a| 
`/storage-provider/file-shares`

|===
+
*Exemplo de cURL*

+
Com base nos privilégios de acesso que você atribui ao grupo de usuários, conforme mostrado no exemplo a seguir, uma ACL é criada e atribuída ao compartilhamento de arquivos.

+
[listing]
----
{
  "access_control": {
    "acl": [
      {
        "permission": "read",
        "user_or_group": "everyone"
      }
    ],
    "active_directory_mapping": {
      "key": "3b648c1b-d965-03b7-20da-61b791a6263c"
    }
----
+
*Exemplo de saída JSON*

+
A operação retorna o Job ID do Job que executa a atualização.

. Verifique se os parâmetros foram adicionados corretamente consultando os detalhes do compartilhamento de arquivos para o mesmo compartilhamento de arquivos.
